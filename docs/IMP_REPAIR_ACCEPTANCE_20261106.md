## R1：评测可信度

已有 H01 身份检查、AG05 评分与 RSI 原子保存继续复用。

- 执行器只接收原始 OCR 与执行身份，不接收金标、预期弃答/风险标签或 split。
- 实际策略、代码、版本与请求指纹绑定；错企业、错来源 hash、改 ID 同源跨 split、重复物理 attempt 均拒绝。
- 固定分母保留 missing/unknown；零正确、关键字段退步、基线缺行、费用未知均不能变成质量通过。
