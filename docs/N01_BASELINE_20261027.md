## 6. 发布边界（仅本地准备）

代码集成与人工批准发布分离：

1. **代码集成**：候选冻结（源码指纹 + manifest + suite id）→ 后端/前端/门禁全绿 → 迁移在空库与旧库各验证一次 → 记录退出码。
2. **人工批准**：由人确认业务口径（税种、通知渠道、支持范围）→ 确认回滚路径（镜像可回退、迁移只前向）→ 才允许任何平台侧动作。

前端、API、worker、迁移与回滚的检查项：

- 前端：构建产物指纹与候选一致；`/api/health` 与 `/api/session` 契约未变。
- API：OpenAPI 路由数与权限矩阵无回归；新增路由必须带独立复核与来源指纹。
- worker：租约与 attempt 语义不变；新任务类型必须可重放。
- 迁移：仅追加；空库→全量、旧库→增量、重跑→不重放三条路径各一次。
- 回滚：镜像可回退一版；迁移不可回退，故新代码必须能读旧数据（expand-and-contract）。

以上均为文档与本地验证，本轮不改 GitHub/Vercel/Zeabur/Supabase 任何设置。
