# 第十二阶段：同屏复核与工作进度

集中复核列表和同类业务复核包的“查看证据 / 打开原件与凭证”在当前页面展开详情，不再切走会计工作区。抽屉并列显示原始附件或原表、来源事实、建议依据、异常、科目及分录。手机上展开为全屏详情，底部保留返回、保存和人工审核动作。

## 原件与权限

- 当前业务事项使用既有业务附件接口，每次读取重新校验当前事项权限。
- 被替代业务来源只使用 `sources/{source}/history` 的冻结历史快照及其附件接口，不以当前新月份授权读取历史期间原件。
- 图片与 PDF 使用经过授权 API 取得的 Blob URL 展示；关闭或切换文件立即撤销 URL。HTML、SVG 或其他格式不作为执行内容展示。
- 银行导入原表通过 `import-wizard/sources/{source}/evidence` 显示对应原行的纯文本；下载通过受保护的 `import-wizard/files/{file}`。不读取凭据引用中的任意 URL。
- 仅有文字凭据索引时明确显示“当前来源只有文字引用”，不会生成虚构原件预览。

## 保存与审核

草稿保存沿用 `PATCH /books/{book}/drafts/{draft}`，审核沿用 `POST .../approve`，均提交服务端返回的最新 `expected_version`。人工审核还要求明确勾选已核对原件、金额和处理，并通过现有金额、权限、期间和异常检查。此处不触发导出。

有未保存修改时，返回或切换凭证会显示继续修改 / 明确放弃修改。键盘 J / K 或左右箭头可切换当前队列，输入控件及组合快捷键不触发切换；Esc 请求返回。抽屉包含焦点边界，关闭后恢复原入口焦点。

包内保存或单张审核后，原批量预览明确暂停，保留其余选择。点击“按当前版本重新准备”重新读取所选草稿版本并生成新复核包，已审核或被替代条目不再提交。重新准备后必须重新明确核对，旧预览不会被描述为仍有效。

## 进度保留范围

`review-session.ts` 只在当前页面进程的内存中保存筛选条件、选中 ID、预览 / 包 ID 及幂等命令键；不保存草稿正文、会计分录、原件或访问令牌，也不写入 localStorage / sessionStorage。离开后返回同一授权范围可以恢复选择与包，恢复时通过既有 GET 接口重新读取当前授权和包检查状态。

身份或授权范围变化、退出、401 / 403 / 404 权限错误以及应用权限更新事件会清空会话。浏览器刷新后工作区选择不会恢复；已保存的草稿和服务端审核记录不受影响。

## 集成

`InlineReviewDrawer` 接收 `session`、`bookId`、`draftId`、可选 `queue`、`onClose`、`onNavigate`、`onChanged` 和 `onBusyChange`。`onBusyChange` 同时报告正在提交及未保存修改，用于根页面防止丢失编辑。根页面在身份、企业授权或退出时调用 `clearReviewSession()`。

此改动不新增数据库表、权限或审核旁路。回归场景覆盖内存范围切换、复制隔离、限定媒体预览，以及浏览器包内修改、重新准备、移动端返回、人工确认后仍等待导出。
