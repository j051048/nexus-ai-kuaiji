## 4. 连续两期、年中与跨年方案

### 4.1 两期

- 第一期：期初确认 → 资料/事实 → 草稿/建议 → 异常/补件 → 复核 → 影子核对 → 对账 → 期末 → 月结 → 报表/归档。
- 第二期：由第一期期末自然承接，不手工重灌期初；往来、固定资产累计、前期调整、规则/权限继承。
- 两期分别正确但衔接错误必须能被比较器发现。

比较器已有合成两期样例：`period_transition` 检查上期 closing = 下期 opening。

### 4.2 年中/跨年

- 年中：年初余额 + 年内累计 + 启用期期初不重复。
- 跨年：年末结转 → 次年期初；往来/未结事项承接。
- 当前只有合成/逻辑测试；**未取得真实适用样本，不能称真实验证**。

### 4.3 核对层次

来源完整性、凭证/记账、账簿/余额、往来/银行、期末/报表；相同口径逐分一致，不用容差。

## 5. 本地工具：独立比较器

`scripts/b08_acceptance.py`

- 只读 JSON 数据集；不导入会计引擎、不修改账本/原件。
- 输入：企业/账套/期间/数据版本、凭证、余额、报表、回执。
- 检查：
  - 跨企业/跨账套；
  - 期间越界；
  - 凭证缺失/多出/重复；
  - 日期、科目、辅助、借贷金额；
  - 余额 opening/debit/credit/closing（防止余额相等但发生额错误）；
  - 上期期末→下期期初；
  - 期初被伪造成普通凭证；
  - 报表来源版本（published 必须当前版本）；
  - 人工回执不得标成厂商确认；
  - 数据版本不一致使旧验收失效。
- 输出 JSON + Markdown；有阻断项退出码 2。
- 不生成“预期答案”；预期必须来自冻结旧账 + 会计确认的规范化文件。

用法：

```powershell
python scripts/b08_acceptance.py --baseline baseline.json --candidate candidate.json `
  --json-out artifacts/b08/compare.json --markdown-out artifacts/b08/compare.md
```

**未实现**：CSV/XLSX 直接规范化、旧软件原生格式适配、自动对账匹配。
