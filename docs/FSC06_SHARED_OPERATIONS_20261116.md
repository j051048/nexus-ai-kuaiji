# FSC06：简洁共享待办、批量办理与协同入口

前置FSC02–05；完整遵守总工作令。复用workspace/firm_tasks、monthly/service_plans、batch_ops、execution/handoff、delivery通知/核查、现有导航与返回来源，不新建平行任务表和五套行业首页。

## 交付目标

企业人员能交资料和处理退回；共享中心人员围绕队列集中处理五家业务；每个异常有实际办理入口，批量不会绕过独立复核。

## 实施

1. 员工首屏：交资料、待我补充、进度；会计首屏：待核验、待复核、待交付；主管首屏：五家公司进度、临期/异常、责任与负载。保留所属单位/身份/期间，折叠重复说明和技术信息。
2. 任务带company/book/period/object/version、原因、责任人、期限、允许动作及返回定位。点击即到准确对象，办理后刷新受影响项并返回原筛选/位置；不可办说明谁来处理并提供接手动作。
3. 实现/补齐已有批量准备、校验、复核排队、已复核集合导出、交付包草稿、失败清单与逐项取消/重试。复核可连续办理，但每笔仍需合法人工决定；不把勾选全部当批准全部。
4. 逐企业记录对象版本、来源指纹、attempt、部分结果和进度。断连恢复显示原结果；取消在途任务区分未开始/执行中/结果未知，未知不能变待重试。公平调度、连接池背压和费用约束保留。
5. 复用受控邀请、站内通知和外发outbox。准备缺件、退回、临期、交付待签收提醒；防重复、频率/收件人绑定、退信/unknown人工核查；本轮仅loopback/sandbox，真实外发关闭。
6. 搜索、过滤、分页按服务端授权范围；页面不把全所大列表加载后再前端隐藏。手机主操作不被软键盘/固定栏遮挡，键盘用户可完成办理。
7. 资金岗的付款准备、审批与银行实际执行分别标记，复用外部回执核对，不因生成付款清单就标已支付。工资、资产、税务等外部办理项也进入统一责任与期限队列，引用权威结果而不虚构执行；工资明细按更窄权限展示。

## 失败测试

- 有待办不能点击、点击错对象、后退丢位置、登录返回丢版本、慢响应复活A公司数据。
- 仅列表可读却显示复核按钮；指派后自动授予权限；审核过程中撤权仍能下载。
- 批量中一户慢/失败拖死其余；重复提交/断网重载生成两份；取消后重试复活全部；旧版本混入导出。
- 提醒重复发送、发给已离职/改联系人、unknown被自动重发；站内查看被记为客户签收。

## 验收

五家公司、五名共享人员、至少两期的真实本地浏览器成功链和部分失败链；桌面手机覆盖企业员工补件→会计连续办理→复核→导出/交付。PG16/17双worker、撤权/版本竞争、不重复副作用；网络延迟/中断下可继续而不重办。每个页面的主要业务任务无需进入技术设置或手工输URL。
