## 1. 实际完成范围

### 1.1 可信端点目录

`ai_trusted_endpoints` + `ai_endpoint_capabilities`：

- 端点身份：协议、主机、端口、路径前缀、服务身份；
- 场景能力：OCR/记账建议/助手，模型标识、结构化格式、图片支持、上下文/输出上限、超时、鉴权方式、价格版本、处理位置声明；
- 同一模型名在不同端点有不同 `endpoint_id`；
- 端点由事务所 owner/admin 创建；企业管理员只能从已批准端点中选择。

### 1.2 企业外发政策

`ai_company_policies` 版本化：

- `managed`、`local_only`；
- 允许场景；
- 允许数据类别；
- 允许端点 ID；
- 原因、更新人、时间；历史不可改。

`AIEndpointPolicyService.check_send` 在发送前检查：

- 当前企业成员/管理权限；
- 场景是否允许；
- 数据类别是否允许；
- URL 是否匹配已批准端点（协议/主机/端口/路径前缀）；
- 模型是否匹配端点能力；
- 仅本地策略是否选择本地端点；
- bearer 端点必须有密钥；无鉴权端点不得收到密钥。

**生产门禁**：生产环境未创建 managed policy 的企业，发送前直接阻断，不再回退 env 端点。local/dev 仍保留 legacy 兼容用于已有测试和本地替身；生产不能依赖该路径。上线前仍应由运维把企业绑定到 managed policy，否则 AI 场景保持不可用。

### 1.3 本地兼容解析

- 新增可选 `allow_single_json_fence`；
- 仅接受“唯一、完整”的 ```` ```json ... ``` ```` 外包裹；
- 内层必须是一个完整 JSON，不接受多段 JSON、前后说明、第二个围栏；
- 默认关闭；启用只作为受控外围兼容，不改变 schema/业务校验；
- 新增 `allow_no_auth`：仅用于明确批准的本机无鉴权服务；无密钥时不发送 `Authorization`；
- 仍保留：无重定向、`trust_env=False`、响应大小/编码/截断/重复键/工具调用/拒绝检查。

### 1.4 上下文与缓存

- 企业政策按数据类别检查；缓存键新增 policy/endpoint 维度；
- 结构化 XML 本地解析不走模型外发；
- OCR 路径在发送前重新做政策检查；
- 记账建议路径发送前做政策检查；
- 助手 worker 在真正发送前做政策检查；
- 沿用既有企业级缓存、权限审查和暂停语义。

**缺口**：当前只做类别级 gating，没有逐字段自动裁剪；提示词/上下文构造仍需按场景最小化。DNS 解析后连接未做地址 pinning，存在 TOCTOU/重绑定残余风险；未实现完整网络层防护。

### 1.5 规则治理

复用现有 `learning`：

- 修正样本 → 候选规则；
- 正例/负例/反例评测；
- 发布必须绑定当前评测；
- 停用/回退保留历史；
- 规则仍只影响未来草稿，不自动审批/记账/扩散。

本批未新建平行规则系统；新增工作主要是端点/政策/口径。

### 1.6 发送、未知、费用

复用：

- `ai_runs`、`assistant_turns` 的 running/succeeded/failed/interrupted/unknown 语义；
- `model_costs` 的 reserved/sent/estimated/uncertain/reconciled；
- 租约、fencing、跨进程并发、企业共享费用账本；
- 响应未知不自动重试。

B05 新增测试确认：解析失败仍保留 `usage`（费用事实不因建议无效归零）；策略拒绝发生在发送前；本地无鉴权不转发密钥。

## 3. 端点与网络边界

- HTTPS 默认；HTTP 仅显式 `allow_http` 且回环；
- 拒绝云元数据、链路本地、组播、保留、未指定地址；
- 私有/回环需 `allow_private`；
- 不允许通配符、用户信息、查询串、片段；
- 不跟随重定向、不继承环境代理；
- 同一模型名必须通过 `endpoint_id` 区分。

**残余风险**：主机名可解析到未校验地址；未做 DNS pin/自定义 resolver；本机测试不扫描真实内网。

---

## 4. 数据政策与缓存

- 企业 AI 默认开启的产品语义保持；
- 暂停后不再授予新的发送许可；在途请求可审计，不能承诺撤回/免计费；
- `local_only` 禁止云回退；
- 生产未配置 managed policy 的企业阻断 AI；local/dev 才保留 legacy；
- 缓存键包含 provider/model/format/prompt/parser/policy/endpoint；缓存读取仍走企业/事项权限；
- 不跨企业复用敏感结果。

---

## 5. 规则、发送与费用契约

- 规则候选不自动生效；评测/发布绑定版本；停用/回退保留历史；
- 同键/换键/未知状态沿用既有任务与费用契约；
- 解析失败不等于零费用；未知用量保持 uncertain，不伪造 token；
- 本地 API 计费零值不等于硬件/运维零成本；
- 多真实调用费用不能合并为一笔；
- 业务结果最多生效一次，费用按尝试记录。

---

## 6. 明确不实施

- 新总账/月结/报表/税务引擎；
- 任意 SQL/Shell/工具执行型 Agent；
- 自动审核、自动发布正式报表、付款；
- 自训练、跨企业训练池、统一上下文；
- 真实供应商联调、模型下载、GPU 集群；
- 生产配置/部署/迁移；
- 完整管理 UI。
