# FSC07：广告传媒项目业务最小闭环

前置FSC04–06。先读总工作令。是否作为第二家试点由FSC01资料成熟度决定，不自动以编号代表上线顺序。

## 修改范围

复用company_master/project、合同与来源版本、业务提交/OA证据、预收预付与settlements、草稿复核、报表/insights。不要给租赁模型改名充当所有项目收入，也不建设新的项目管理ERP。

## 实施

1. 项目/合同/客户/供应商身份与范围绑定，保存合同版本、变更、交付/验收节点和获批确认策略。不同公司同名项目不能合并。
2. 分开记录合同额、已收款、已开票、经核定确认收入、待确认收入、预付、已确认成本和未结事项。合同签署、收款、开票都不能直接等同收入。
3. 外包/媒介预付对接既有往来；凭验收及政策核定成本，支持部分核销、跨期、更正和退回，不重复计算费用。
4. 项目毛利由可追溯的已确认收入/成本计算，展示期间和覆盖范围；间接分摊需企业批准方法。缺成本显示不完整，不以0显示高毛利。税费适用性由已核定政策决定，不硬编码文化类税费。
5. 现有工作台提供“项目缺什么→补件→生成/修正草稿→独立复核→往来处理→交付”的路径，合同详情与原件就地查看。

## 红测与验收

- 未验收自动确认收入；跨期收款被重复计收入；合同变更后旧预览仍入账。
- 预付未核销就算成本或核销两次；错误项目/企业分摊；退款删除历史。
- 缺成本仍展示完整毛利；税费政策未知被默认套用；项目制单者自审。
- 一笔分期项目覆盖两期、部分验收、部分收款、预付核销、更正和最终交付；PG16/17金额/隔离/并发与有数据恢复；桌面手机真实办理通过。缺客户合同和策略时完成合成样例与真实启用拒绝，不宣称客户模式已认证。
