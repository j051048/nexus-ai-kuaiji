## 2. 实际完成范围

### 2.1 子账与银行

- `subledger_items`：长期应收/应付/预收/预付，控制科目+版本、往来方、原日期/到期日、金额、来源。
- `subledger_allocations`：关联 B03 已记账收付款凭证；不重复生成收付款分录。
- `subledger_allocation_reversals`：撤销核销，保留原分配。
- 部分核销、幂等键、超额拒绝、账龄（历史 as_of）、控制科目勾稽。
- `bank_statement_lines` / `bank_recon_adjustments`：流水匹配正式现金分录；调整项不自动生成凭证。
- API：`/api/subledger/*`。

### 2.2 期末草稿

- `periodic_rules`：固定金额计提配置。
- `periodic_assets`：直线法折旧/摊销基础（原值、残值、月数、开始期间、费用/累计科目）。
- `periodic_runs` / `periodic_drafts` / `periodic_draft_lines`：确定性草稿、输入指纹、复核、记账回执。
- 结转：按损益类科目余额生成“本年利润”结转草稿；排除已记账 closing 凭证，避免循环。
- 所有草稿必须复核后调用 B03 `post_manual`，不直接写正式凭证。
- API：`/api/periodic/*`。

### 2.3 报表

- `report_templates`：小企业基础模板 v1（技术候选）。
- `report_runs`：期间、模板版本、输入指纹、内容 JSON、哈希、状态、版本、复核/发布。
- 资产负债表、利润表、基础现金流量表；勾稽检查：
  - 资产=负债+权益（+未结利润）；
  - 现金净变动=经营+投资+筹资+未分类；
  - 未分类现金流阻止核验。
- 发布需锁期；发布后内容快照不可变；API `/api/reports/*`。
- 报表输入变化后旧报表不能复核/发布（测试覆盖）。

### 2.4 月结

- `internal_close_runs`：预检、复核、锁期、发布状态；检查项 JSON。
- `internal_period_locks`：内部锁期；B03 `_book` 检查，锁期后拒绝记账。
- 预检阻断：未记账期末草稿、未审核草稿、子账控制差异、银行未处理、试算不平、报表勾稽/未分类。
- 复核人≠预检人；锁期重新校验报表 fingerprint；重开明确 409。
- API：`/api/b04-close/*`。

## 4. 子账、核销与总账勾稽契约

- 未结事项跨月保留，不按月复制。
- 核销只改变事项余额/分配关系，**不生成第二张收付款凭证**。
- 分配合计 ≤ 事项剩余、≤ 收付款凭证控制科目金额；同一事项+凭证唯一。
- 撤销核销新增反向记录，不覆盖原分配。
- 账龄按显式 `as_of`，不按查询当天重写历史。
- 控制勾稽：应收/预付按借方；应付/预收按贷方；差异阻断月结。
- 银行流水匹配要求金额/方向一致；未解释差异不能自动配平。
- **限制**：银行 `passed` 目前只要求流水全匹配且无 open 调整，未强制账面-对账单差额等于已批准调整；完整调节表未完成。

## 5. 计提/结转政策与幂等

- 计提：固定金额；折旧/摊销：直线法；结转：损益类→本年利润。
- 生成键：`book_id + run_key`；相同依据重复生成返回原草稿。
- 草稿版本递增；复核人≠编制人；记账后回写正式凭证。
- 已记账结转参与总账，但报表计算排除 closing 凭证；避免重复结转。
- 依据变化自动失效不完整：当前按 run_key 复用，变更需人工处理；未实现完整“依据变化→旧审核失效”。
- 结转不支持红字/负数损益、辅助维度、年度利润分配。

## 6. 报表公式与版本

- 唯一来源：B03 绑定期初 + 已提交正式分录。
- 资产=负债+权益+未结利润；利润=收入−费用；现金净变动=经营+投资+筹资+未分类。
- 模板/内容/输入指纹版本化；已发布内容不可变。
- 报表生成不等于发布；复核不等于月结完成。
- 未实现：比较期、YTD、附注、权益变动表、PDF、历史权限下的完整快照授权。

## 7. 月结状态与权限

```
draft → preflight_failed / preflight_passed → reviewed → locked → published
```

- 预检阻断项不可“忽略”放行；无可解释例外机制。
- 复核/锁期/发布重新鉴权 + 版本检查；锁期后 B03 拒绝记账。
- 重开明确拒绝，未实现影响分析/后续期间依赖。
- 旧 `closing` 交付工作流未改；B04 内部月结与其并列但语义不同。
