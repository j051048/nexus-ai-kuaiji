# FSC09：商贸单据匹配、往来与库存证据

前置FSC04–06；先读总工作令及FSC01确定的存货权威系统。不要因规划写“贸易”就建设通用进销存。

## 实施

1. 基于已有来源导入、客商审核别名和原件服务，接合同/订单、发货/收货/验收、发票、银行流水。对象有源系统、外部ID、版本、行身份和原件hash；不能凭相同金额认定同一业务。
2. 匹配支持一对多/多对一、部分履行、分期开票付款、退货、跨期与数量/金额差异。约定单位、币种、税额与不含税/含税口径；容差有批准版本，不用浮点或模型凑平。
3. 匹配结果为“相符/部分相符/有差异/证据不足”，提供差异来源、负责人和办理入口；四流相符不等于证明真实贸易或排除违规。
4. 先复用外部库存权威系统的期间成本/出入库/结存快照，生成有来源的成本结转草稿并独立复核；不重复接管库存权威。若客户明确需内部计价，须先确认计价方法、期初、数量单位、退货/暂估/后补票与负库存政策，再作为独立子项实施，未完成则该能力保持关闭。
5. 应收账龄基于合同到期日、未结余额与有效核销，不是凭证创建时间；两金/周转展示口径、期间及覆盖率。缺存货依据显示未核实，不填0、不宣称自动完成国资考核。

## 失败测试

- 同一合同/验收/发票额度重复占用；并发匹配超额；跨企业相同编号错误合并。
- 退货重复冲减/删除历史；跨期重复结转；来源库存快照升级后旧成本仍可复核导出。
- 不同单位、税口径、数量精度直接比较；部分收货误判全量验收；未开票应收在账龄中消失。
- 缺期初/成本政策/库存快照却能生成成本；自审、撤权、锁期后修改。

## 验收

至少两期合成购销链，包括部分收货/发货、分期开票、收付款、退货、库存快照更正和成本草稿复核。PG16/17并发占用、来源失效与权限；前端逐差异办理及回退；有数据恢复核对数量/金额/来源与未结余额。真实ERP接口或库存方法未确认时，清楚划定本地可用与客户待验范围。
