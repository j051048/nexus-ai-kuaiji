# FSC13：内部与 T+ 损益结转权威及防重复

优先级 P0。先读 `docs/FSC_EXECUTION_MASTER_20261116.md` 和 `docs/FSC13_17_SUPPLEMENT_MASTER_20261117.md`，继承全部执行边界。前置 FSC01 盘点、FSC02 核算/导出基础；本批是 FSC14 和最终 FSC12 的输入。

## 目标与范围

同一企业、账簿、期间的一次损益结转，在内部记账、T+ 回流及管理报表中有明确权威和对应关系，不能重复记账，也不能通过删历史或忽略全部外部凭证来“去重”。

先核实并复用：`nexus_backend/app/tax/pilot.py` 的 authority/source_of_truth；`app/periodic/service.py` 的结转生成/复核/记账；`app/reports/profit.py`；现有 accounting 记账、integrations/FDE 导入信封、冻结导出/回执、利润页面与来源下钻。路径仅为搜索线索，不新建结账引擎、报表引擎或第二套外部凭证账。

只处理结转权威、业务身份、源版本和贡献口径；不扩为真实 T+ 连接器、自动结转、税务申报或会计制度重写。

## 实施顺序

1. 梳理 internal、tplus_voucher、hybrid 等实际已有模式：逐项写明谁产生正式事实、外部数据是副本/核对证据还是新的记账来源。hybrid 不能表示两边可对同一经济事项各记一次。模式和生效期来自已确认政策，不由页面临时选项决定。
2. 设计或补全两层绑定：第一层是企业、稳定账簿、期间、结转类型/批准范围及原经济业务的唯一身份/有效结转约束；第二层是来源系统/对象版本、请求指纹、内容摘要和确认依据。来源版本或摘要变化不能自行产生第二次结转资格，必须核对原结转及冲销/更正关系。跨月物理账套不能让同一经济身份漂移。
3. 区分“导出副本再导入”和“外部独立生成结转”。相同金额/摘要/科目不构成同一业务证明；同外部 ID 同内容幂等，同 ID 异内容冲突。无法确定等价关系时进入人工核对，不丢弃、猜测或自动正式记账。
4. 同一逻辑账簿内，重复来源只能成为原记录的外部对应证据，不能再贡献一次正式余额；若是独立的外部账簿，只建立核对映射，不跨账簿强行合并。内部已记账后发现外部另一笔真实结转，显示冲突并走受控更正，不删除任何一边。
5. 权威模式切换需影响预览、权限、政策版本和既有未完成任务检查。生成/复核/记账/导出/回执接纳均重验；有未决或 unknown 事项时不得借模式切换另起业务绕过原链。
6. 利润报表使用确定性行贡献，区分正常收入成本、结转转出、冲销和更正。内部/T+ 的结转不会把经营收入成本算两遍或全部抵成零；真实调整仍进入正确期间。四层来源下钻复用现有组件，缺来源明确未核实，年累计缺月份保留不完整，未知不补零。
7. 在原月结/利润页面显示权威来源、期间、核对差异及“查看依据/交会计核对”。历史凭证和文件保留，不以隐藏冲突换绿灯。

## 先写失败测试

对照现有用例，先复现尚未被覆盖的真实缺口，至少覆盖：

| 场景 | 必须证明 |
|---|---|
| 内部已结转，同一导出回流两次 | 只保留一份正式账务贡献；回流可追溯，不重复记账 |
| 外部权威已经有结转，再请求内部生成/记账 | 按政策阻断重复来源；合法预览不会成为第二份正式账 |
| 相同金额但不同来源/真实调整；同 ID 异内容 | 前者不误去重，后者冲突；不能靠金额 hash 掩盖 |
| 内部/T+ 导入与结转生成双会话竞争 | 最多一次有效结转，冲突返回受控结果，没有部分提交 |
| 来源或权威政策变更后旧预览/旧审核提交 | 不接受过期绑定；确认新政策不恢复旧对象审批 |
| 同一已记账业务以新 source_version 回流 | 只核对或进入受控更正，不因新指纹再次贡献金额 |
| 结转红冲/更正、跨年、净利润为零、混合凭证 | 行贡献和累计核回，不凭摘要猜分类，不除零或补未知 |
| 跨企业/账簿/期间映射、只读直接写、恢复后重放 | API 与受限 DB 拒绝；恢复不重结转 |
| 外部返回 unknown、乱序或重复回执 | 保留外部未知事实，不自动发送或猜已记账 |

样本金额及期望贡献先写出可人工核算明细，不能用待测算法计算测试期望。历史无法识别的结转进入待核查清单，不批量补造审核。

## 验收与交付

- 本地成功链：确认权威政策→两期正常凭证→独立复核/正式记账→结转→冻结导出→本地外部回流→核回利润下钻；两企业隔离、跨年及真实更正同时通过。
- PG16/17 受限角色直接写负向、唯一性与双会话竞争通过；新增前向迁移首次应用/重入/有数据升级通过。
- 桌面/手机显示同一权威来源与金额；切换企业、撤权、旧响应、深链接及返回队列不串范围。
- 非空恢复包含内部结转、外部映射、冲突和更正历史，恢复后相同请求不会再次贡献金额。
- `docs/FSC13_ACCEPTANCE.md` 保存权威矩阵、失败→修复证据、真实命令与候选指纹；把真实 T+ 模板/回执认证单独标为未验。本地模拟绿灯不能写成已接通 T+。
