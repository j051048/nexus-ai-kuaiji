# 第六阶段验证记录（2026-10-12）

## 交付

企业模型费用配额、用量统计与运行监控已接入第六阶段代码。每次模型请求在外发前预留费用，按供应商报告 token 和明确配置的人民币费率估算；未知费用保留预留，往月尚未核定的占用不会跨月消失。管理员可以依据供应商结算核定费用，并保留原估算、用量、报价、预留和审计。

同步 OCR、后台每次 OCR 尝试以及模型分录建议都执行预算检查。额度不足、报价缺失、单次预留不足或已有待确认超预留费用时，不发送新的模型请求；并发竞争不会重复消费最后一份额度。供应商报价由部署环境明确配置，不内置实时价格，不自行换算美元或假设未知为免费。

新增企业监控页面和站内告警，显示任务失败、队列等待、后台心跳、费用风险及人工异常积压。预算管理员/企业财务可按权限读企业汇总；员工、部门人员及仅有账套复核授权的用户不会获得全企业费用和监控数据。监控权限不打开未移交原件，告警知晓与费用核定也不审核凭证或消除票据异常。

## 关键限制与一致性

- 人民币费用以整数微元计算，预算输入两位小数，单价及估算保留六位。模型供应商的实际账单可能有缓存、图像或其他费用口径；本软件控制的是按配置费率和预留计算的应用预算，不能替代供应商侧的实际扣费上限。
- 未发送的本地拒绝不占费用；请求超时、断网、取消、撤权或回执丢失不被当作免费。已取得有效用量，即使票据/分录结果被拒或权限撤销，仍记录该次费用事实。
- 对每个模型请求只有一份成本记录，结算需要服务端私有令牌。重放原请求不会重复预留；新尝试独立计量。成本核定禁止提前释放仍在执行的记录。
- 月份按上海时区，记录时间用 UTC。往月未知预留计入当前预算风险，往月已知费用归原月，不双算。超预留必须核定，不在月初自动消失。
- 费用核定是预算管理行为；企业财务可读汇总与知晓提醒，不能因此修改费用政策。预算与运行权限不扩大业务事项、附件或账套权限。
- 只读概览不扫过期成本、不写告警。后台每十秒维护心跳及提醒，显式刷新也可更新提醒；相同风险不改变版本，新增风险会重新提示。
- 人工异常使用已授权事务中的当前核对快照，排除正在后台处理的待完成状态；GET 不登记原件异常。额度告警的知晓不会恢复额度、重试任务或自动审批。
