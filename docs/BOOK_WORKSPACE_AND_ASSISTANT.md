# 账套常驻工作区与统一助手

## 常驻账套壳

当前账套的资料与流水、业务匹配、凭证复核、参考余额、月结预检和交付回执在同一个
`BookWorkspaceShell` 内切换。进入这些步骤时，左侧账套列表、账套标题和五步流水线保持可见，
不再跳转到会卸载账套壳的独立页面。

- 第①步回到原始流水，第③步回到凭证队列；
- 第②步显示业务与资金匹配、发票导出表、预检与挂账；
- 第④步显示参考余额、月度差异和月结锁期；
- 第⑤步显示冻结导出清单与逐行回执核验。

余额表单有未保存内容或嵌入页面正在执行写操作时，五步导航和账套切换同步禁用。页面切换后，
已选账套与期间仍保留在 URL 和工作区状态中。

## 统一右侧助手

全账套对话和当前凭证依据现在共用一个非模态右侧抽屉：

- 从顶部“问会计助手”进入全账套对话；
- 从凭证复核的“会计助手”进入当前凭证依据；
- 抽屉顶部可切换“当前凭证 / 全账套对话”，两个模式保持各自已加载状态；
- 抽屉不再添加全屏遮罩、不锁定背景滚动，主工作区仍可查看和滚动；
- 关闭按钮与 Escape 同时关闭两种模式，所有回答继续只引用当前已授权、已保存资料。

左侧导航不再重复放置“查找企业与任务”和“会计助手”，这两个全局工具只保留在顶栏，为账套与
快捷入口释放垂直空间。

## 当前边界

参考余额、月结、交付、固定事项、收付款核销、月度简报、财务软件接入、科目模板、审核样例、
长期账套及旧账迁移均已通过同一 `embedded` 契约迁入常驻壳。账套级子视图切换时，左侧账套
列表、当前账套标题与五步流水线不再卸载；各子视图仍保留独立地址，刷新和深链可直接恢复。
