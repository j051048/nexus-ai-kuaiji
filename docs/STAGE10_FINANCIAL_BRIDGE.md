# 第十阶段：T+ 文件接入底座

当前客户仅确定使用 T+，具体产品版本、部署方式和接口授权尚未确认。本阶段实现中性文件接入、版本化映射和冻结交付意图，**没有连接真实 T+，没有把中性 JSON 宣称为 T+ 原生导入格式**。

## 当前可操作的闭环

1. 会计进入账套的「财务软件接入」，填写客户外部账套标识、已核验的科目和辅助核算映射。配置按长期账套保存版本；修改配置须同时具备当前期间复核权限和明确的长期账套管理授权。
2. 下载中性模板，将客户导出的科目、往来、项目、银行账户、凭证或余额转换成模板中的 JSON / CSV。文件须明确本企业、物理期间账套、外部账套及月份。
3. 预览记录后人工确认。外部记录按稳定编号保留，只用于核对参考；不会自动创建流水来源、凭证或期初余额。相同编号不同内容会阻止确认，原记录不会覆盖。
4. 凭证完成会计复核并导出后，准备冻结交付包。每个导出只有一个持久交付意图，清单内金额、科目、辅助项、导出版本和配置版本一并冻结。
5. 将交付包转换为客户实际版本支持的导入格式，在客户软件中操作导入，再通过现有「导入回执核验」逐笔核对结果。缺少科目或辅助项映射时无法准备交付包。

现有回执模板按原导出的本地科目和辅助项核验；交付包中的字段已映成外部编号。因此客户实际回执也须按**该冻结包的配置版本**归一化回本地编号，并保留真实外部凭证号和原文件作为核对依据。不能使用后来更新的映射，也不能把外部编号直接当作本地科目核验成功。如果多个本地值映到一个外部编号，不能假定映射可逆：须结合原 intent 的逐行证据，由人工核对，无法唯一还原时保持差异。自动归一化和厂商回执认证属于后续版本适配器的工作。

文件模式始终返回 `live_enabled=false`。交付意图停在 `awaiting_adapter`；调用发送入口返回 409，后台不会发送或自动重发。已使用的外部账套标识不能因切换月份或失去旧月份权限而重新绑定。

## 数据和接口边界

所有接口位于 `/api/books/{book_id}/integrations/tplus`，实时使用数据库权限，撤销账套授权后原预览和交付包也不可读取。

| 路径 | 用途 |
|---|---|
| GET 空路径 | 配置、能力边界及分页历史 |
| POST `/configuration` | 保存新映射版本 |
| GET `/template` | 本账套中性参考模板 |
| POST `/imports` | 限定范围的文件预览 |
| GET `/imports/{id}` | 读取原预览 |
| POST `/imports/{id}/confirm` | 按原指纹人工确认参考记录 |
| POST `/outbox` | 对已审核导出冻结一次交付意图 |
| GET `/outbox/{id}` | 下载原交付包 |
| POST `/outbox/{id}/dispatch` | 当前拒绝真实发送 |

导入单文件最多 2 MB、1,000 条记录；整个 HTTP 请求限制为 4 MB。JSON 与 CSV 使用相同的金额字符串、期间和企业范围校验，金额不以浮点数传输。

PostgreSQL 接入表启用 FORCE RLS。数据库校验配置的当前期间和长期账套范围、参考记录与原预览的绑定、冻结包的逐张凭证和逐行映射。配置、已确认参考和交付意图保留原记录；worker 无接入表访问权限。

## 后续真实版本适配的必要条件

畅捷通官方的接入指引包括开发者身份、创建应用和用户授权，SDK 文档给出了 `appKey`、`appSecret` 及 T+ 请求示例。具体产品和客户授权范围须按实际版本核实；本次未申请应用、读取客户凭据或安装未经核实的适配器。[官方应用接入指南](https://open.chanjet.com/docs/quickstart/ksrm/yyfblc?c=squhkjyc11391)、[官方 Python SDK](https://github.com/Chanjet/chanjet-openapi-python-sdk)

版本适配器应实现以下契约，并在沙箱及试点账套验证后再启用真实读写：

- 明确目标产品、版本、企业/账套身份、授权有效期，以及支持的科目、辅助项和凭证接口。
- 只消费已冻结的交付意图；认证提交和结果查询分开。原导出、配置与业务幂等号不能在发送时临时改写。
- 发送前实时校验账号、客户授权、账套归属和供应商限流。把已授权的发送状态与持久 outbox 事务连接起来。
- 保存可验证的厂商回执、外部凭证号与查询依据，逐笔比较金额、科目、辅助项和借贷平衡。
- 遇到超时或未知结果先查原操作号，不自动重新创建凭证。部分成功要保留逐笔回执；只有能证明未接收的项目才进入受控重试。

当前阶段对接入底座的验证使用明确的合成文件、受限本机 PostgreSQL 和浏览器操作。生产 Supabase、真实畅捷通授权、客户软件导入格式及真实月份月结仍需试点验证。
