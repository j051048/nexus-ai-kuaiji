# FSC08：物业服务分期与食材采购证据

前置FSC04–06。完整遵守总工作令。两条业务分别验收，物业服务费与食材采购不能混成一个算法。

## 范围与实现

1. 物业服务：复用合同版本、计划、分位尾差、预收核销和复核设施；建立明确的服务履行/确认策略，区分服务费、代收水电、押金、预收与收入。不能只更改lease_contracts标签套用租赁逻辑。
2. 支持中途开始/终止、跨月/跨年、减免、退款、合同变更与已确认期间保护；单价/天数/尾差方法必须来自企业核定政策。未知策略仅合成预览。
3. 食材采购：导入合同/订单、验收或入库、发票、付款来源，复用客商/单位映射和证据政策；支持部分验收、分批开票/付款、退货、合理数量差异与损耗核定。
4. 库存权威系统若在外部，先接收受控出入库/消耗/结存快照并核对，不自创一套库存账。食材数量单位和批次有明确映射，无法换算时拒绝。
5. 农产品等特殊税务口径仅接入企业审核过的适用政策/底稿和来源，未确认时显示待核定；不得从供应商名称、发票有无或行业profile自动得出抵扣结论。
6. 页面按“服务收费”与“采购验收”任务区分，复用导航；缺件从任务就地催补，办理后返回。

## 失败测试

- 预收/押金直接算收入；部分月按整月；合同变更覆盖已记账期间；尾差累计不守恒。
- 一张验收单被重复消费；采购/验收/发票数量口径不一致仍通过；退货未冲减可付款余额。
- 未知税务政策默认可抵扣；跨企业复用供应商/合同；零/负/溢出/小数单位错误未拒绝。
- 退款或作废重复执行、绕过独立复核，原件更新不使旧草稿失效。

## 验收

分别跑两期服务费与完整采购例子，含部分执行、退货/退款及更正；金额/数量守恒，已冻结历史不覆盖。PG16/17权限/幂等/并发、种子恢复、桌面手机真实任务链通过。不得把本批称为完整食品供应链或自动税务申报系统。
