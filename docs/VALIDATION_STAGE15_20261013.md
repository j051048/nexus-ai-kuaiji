## 关键边界

- 会话仅本人可见，管理员不能越权读聊天。本人／部门／企业权限、账套授权和客户状态先于列表计数及分页检查；撤销任一范围授权后，历史问题、回答和任务回执隐藏。
- 空资料范围不查询或识别全企业事项。模型输入只来自显式范围的当前已保存事实、当前 OCR 安全结构摘要及阻断提示；不发送附件原件、识别全文或其他员工的事实。
- 模型回答使用强类型结构，禁止任意工具调用、额外参数、跨范围引用和无授权证据。金额保持确定性精确字符串；模型无法执行审核、过账、导出或事实修订。
- 一轮问题及消息幂等、同一会话最多一轮在处理。未发送任务按有界租约恢复；已发送未知结果停止自动重发，旧 worker token 失效。HTTP 登录、关闭原服务器、恢复数据库后实际完成队列已验证。
- 预览固定候选、30 分钟失效，当前版本、科目、规则、附件、期间及授权变化后无法确认。原生 SQL 校验同事务确认与真实队列／草稿证明，伪造回执及只确认不执行的事务无法提交。
- 公司额度同时覆盖 OCR、分录及聊天，单次预留由服务器策略决定。未知费用保留，已收到的用量在撤权后仍可核定；过期回复不发布。旧预算客户端省略新字段时保留原对话预留。
- 助手与 OCR／分录实际领取共用最多两槽；两个企业占槽后第三企业不能突破，反向领取也不能跳过助手。即便有全局空槽，同公司两类任务仍互斥；释放后恢复领取。
- 专用对话心跳与记账心跳分别计算，任一不能掩盖另一类任务后台故障；聊天排队、连续失败和费用风险进入现有站内提醒，聚合不泄露私有问题。
- 手机面板无横向溢出；会话切换后 Escape 和 Tab 可用，恢复任务可跳转到回执中实际生成的草稿。

## 本轮修复

实际验证发现并修复：API／数据库跨主机时钟导致任务暂不可领取；消息原生 guard 读取私有列的角色权限；撤权后丢失已返回用量；真实网络断连错误分类；独立 worker 未装配 OCR 和历史往来核对依赖；会话切换导致键盘焦点丢失；隐藏标签挤占手机输入区域；助手跳转残留上一工作页状态、刷新错误账套。新增原生修复全部通过前向迁移，未覆盖旧文件。

费用 UI 旧用例对“两类报价”的断言更新为三类报价后通过。Windows 单次回环端口连接失败未改动产品逻辑，独立重跑通过。
