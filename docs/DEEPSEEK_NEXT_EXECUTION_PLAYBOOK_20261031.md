```text
4. 记录吞吐/p50/p95/最长等待/饥饿/锁等待/连接峰值/内存峰值、失败和未知项。失败不从分母消失。
5. PG16/17跑同一语义/故障子集；各自容量结果单独报告。最终200家混合负载至少完成一轮和60分钟稳态观察，不能把两个版本结果相互代替。

验收：
- 无跨企业泄漏、重复业务提交、重复未知调用、负费用、取消复活、进程退出后假心跳。
- 批次计数与逐项/正式账/包清单守恒，失败可定位并按资格单项恢复。
- 候选与数据摘要固定，脚本可复跑，超时明确失败，不忽略超时样本。
- 200家开期60秒/导出5分钟仅作为需注明负载的目标；未达标如实报告，不放宽正确性。测的是系统容量，不是证明一个会计能处理200家全部业务。
```

## DCP11：受限只读取证循环与任务级评测

```text
执行 DCP11。已有助手能取服务端授权事实、编译ContextPack、校验引用和发布；本包补可恢复的有限领域调查，不增加通用自主Agent。

前置：当前助手任务级离线基线、阶段事件、诊断分页、费用/attempt PG16/17门槛通过；DCP03和DCP05提供准确正式成果与人工接手语义。
范围：assistant现有worker/turn/lease、ContextPack/fact_validation、execution、H01/AG05/FakeProvider；tools/离线investigation仅作参考/复用，不直接把缺少持久围栏的实验模块当生产执行器。

分三步，每步验证后再推进：
A. 注册三个类型化只读域接口：凭证状态、月结阻断、交付/回执状态。服务端注入actor和scope；模型不得指定任意企业ID/SQL/URL。
B. 接入持久步骤：plan→read→validate observation→下一步/answer/handoff。首版上限3次工具读取、最多4次模型调用（含最终回答），另受总token/金额/墙钟预算限制；限额服务端确定。
C. 扩展任务回放：围绕“本月为什么不能交付”，对比既有单轮与有限循环，覆盖正常、缺资料、银行/子账差异、冲突、撤权、超额、unknown、覆盖不全。

必须保持：
1. 每步发送/读取前以及结果接纳时重检权限、事实版本、租约和预算；分页绑定cursor/范围/来源指纹。
2. 每次实际模型发送独立attempt/费用链，不能沿用一个turn已发送标志掩盖第二次调用；总预算预留与结算可核对。
3. 发送后unknown停止该调查，保留费用和人工接手，不自动换模型/重发。首版不新增供应商fallback。

先红测试：跨企业/旧版本工具结果、取证后撤权、同ID不同内容、注入指令、超额、重复工具、循环不收敛、取消、发送后崩溃、双worker竞争、两步累计费用/未知usage、恢复多一次调用、伪造事件或提前发布。

验收：

- 独立holdout不参与调prompt；未知/失败/缺失留在分母；不以候选自报评分，报告工具选择、事实正确性、弃答/误报漏报、成本/调用数与基线差异。
- 桌面/手机显示查了哪些类别、还缺哪些资料、交给谁；保持现有单轮路径可用和受控开关默认关闭。
- 真实模型质量X未验证，未获新授权不得启用生产多步循环。不存在真实效果证据时只宣布本地工程/契约通过。
```

## DCP12-B：真实试点，当前只编制方案，不执行

```text
本段只有用户后续明确授权真实企业/真实模型/真实渠道及部署范围后才可执行。收到整份手册不等于获得这些授权；当前只准备材料清单与验收表，不请求密码或令牌。

1. 企业覆盖至少两类简单业务画像，明确排除库存/复杂成本/多币种等尚不支持范围；不因无法处理就默认为零或“不适用”。
```

## 后置工程整理，不抢主线

- 仅抽出App中的路由/鉴权边界与已重复的轮询，新增挂载/权限契约回归；不同时改数据库方言。
