# FSC16：维修包干覆盖、额度累计与实际结算冲回

优先级 P1。先读 `docs/FSC_EXECUTION_MASTER_20261116.md` 及 `docs/FSC13_17_SUPPLEMENT_MASTER_20261117.md`。前置 FSC15、FSC02 核销接口、FSC05 证据政策；依赖未满足先做契约和红测，不造第二套费率/核销系统。

## 目标与已有能力

从“填覆盖范围和切换理由即可通过”升级为能核验包干合同、覆盖车辆/期间/项目、额度占用及实际结算依据的办理链。复用 `TaxCostService`、现有维修来源/批次/规则、FSC15 费率版本、settlements/FSC02 核销、原件、会计更正与人工待办。

不得把合同额度当实际费用或付款，不把实际维修发票金额直接再加到包干费用上，不因写了自由文本“包外”就放行重复成本。

## 实施步骤

1. **契约先明确**：确认包干是哪种计价和结算方式、合同额度是否限制支付/服务量/费用确认、适用车辆与日期、覆盖和排除项目、特殊项目批准、额度重置范围、超额处置及退款是否恢复额度。企业未确认前只允许合成策略测试，真实功能安全关闭。
2. **来源与唯一身份**：维修单/合同计划/发票/结算事实各有来源 ID/版本/hash，绑定公司、合同、车辆及发生期间。多个文件描述同一维修义务时保留引用，避免多算；相同日期/金额不是自动去重依据。
3. **累计台账**：复用可用余额机制或增量领域记录，明确预占、确认消耗、释放、更正的时点。多月月账套共享合同生命周期身份，按政策跨月累计/重置。相同草稿预览或重试不得累计多次；预占转确认不能双计；额度释放须有原占用引用。
4. **包内与包外判定**：结构化覆盖/特殊项目按生效版本匹配。无法匹配的项目转人工核定，保存权限、依据和版本；自由文本仅解释，不等同于批准依据。真实超额单据和原件仍可按权限留存，额度阻断针对未经批准的占用/采纳等受控动作，不隐藏真实发生额或要求把单据改小。切换包干/按车/实际模式先给已占额度、已有计提及来源冲突影响预览。
5. **实际结算与冲回**：若批准政策采用暂估后实际结算，实际结算引用原计提/分配，明确本次消除暂估和新增实际金额，形成差额或冲回加重计的受控草稿；不反复累加成本。支付及银行核销另外留痕，支付不会自动改变成本确认。政策不要求冲回的固定包干，不机械套用“实付全冲”。
6. **部分与跨期**：部分结算、多次结算、退款、红字、更正、换车、合同终止、跨年余额都通过引用和确定性整数分/Decimal 核回。已锁期影响走当前允许期间的追加更正，不回写历史。尾差处理方法版本化，不自行扩大允差。
7. **办理界面**：在现有维修批次显示合同/覆盖项目、限额/占用/可用、暂估/实际/差额、原件及下一步。支持直达特殊项目核定与冲回草稿、复核和结果查看，办理后回原队列；无权限只显示负责人，不泄露其他公司的金额。

## 必须先失败的场景

| 场景 | 验收断言 |
|---|---|
| 两月分别未超月金额，合计突破合同上限 | 依批准的累计范围阻断；不因切换月账套重置额度 |
| 两会话同时消耗最后额度 | 不超额、不丢账，失败方明确剩余额度/版本冲突 |
| 同维修单从包干与实际两入口登记 | 同一费用义务不重复贡献；合理不同项目不误合并 |
| 特殊项目仅填理由，无批准证据 | 不绕过覆盖/额度守卫；核定权限与制单复核分离 |
| 反复预览/生成/重试/取消 | 不重复预占/确认/释放，不复活已取消项 |
| 暂估 10000 分、实际 12000 分的合成政策 | 如该政策要求替换暂估，最终累计成本 12000 分，不是 22000 分；原始和更正链均保留 |
| 部分实际结算后再结清、重复冲回、同 ID 异内容 | 每部分有原计提引用，不超冲、不重复记账 |
| 退款或付款直接被当作额度恢复/费用冲减 | 只能按批准政策和对应事实处理，不由资金流推断成本 |
| 政策/费率/车型/覆盖版本变化、撤权、锁期 | 在接纳和发布时重新校验，旧审批不被自动继承 |
| 跨企业合同、只读直写额度、恢复重放 | 服务与受限 DB 拒绝越界，累计状态与来源恢复一致 |

测试数值只是离线会计政策样例，不是客户真实算法。每条金额断言同时核对来源贡献、余额与正式凭证，不仅核对 API 返回 success。

## 验收与交付

- 两企业/两期含跨年，正常包内、经批准包外、部分结算、差额更正及拒绝超额完整链；按原权限完成制单→独立复核→记账/导出，期间权威沿 FSC13。
- PG16/17 双会话额度竞争、重复结算/冲回、来源/权限竞态、受限角色直写与企业锁回归，不能改回全局锁掩盖并发问题。
- 桌面/手机从阻断项直达合同/原件/核定/草稿再返回。新增结构有共享契约坏形状测试；UI 不在前端自行决定额度或费用。
- 非空恢复包含合同/费率/覆盖版本、占用/释放/结算/冲回及原件，核对恢复前后累计、剩余和凭证一致，恢复不自动结算/支付。
- 输出 `docs/FSC16_ACCEPTANCE.md`：批准政策或合成政策标识、支持/不支持场景、红绿证据、金额核回表和候选指纹。真实合同未提供不宣称实际包干结算通过。
