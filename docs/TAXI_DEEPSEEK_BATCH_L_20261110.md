   文件若移动，先搜索实际位置；报告中的截图坐标、数量、性能数字不能直接冒充当前基线。
2. 记录 HEAD、已跟踪/未跟踪改动、拟修改文件摘要与归属。既有 A–H、C01、其他智能体的实现全部保留。不 reset/clean/stash，不覆盖整文件、不回退他人修改、不整仓格式化。动共享文件前重读当前内容；出现并行变化时做最小合并，无法确定语义时只阻断冲突小项并说明，继续其他独立工作。

4. 本轮是前端增量收敛：沿用现有 React、路由、权限投影、业务服务、请求范围绑定和构建工具。不安装 Astryx、motion-prompt 运行时或其他整套 UI 库，不升级 React，不引入全局 reset、远程字体/CDN，不改 skills、锁文件或另造导航/状态机。确有必要的新依赖必须先提出独立评估，当前先用已有能力完成。

### 必须保留的业务边界

- 仅本地隔离环境和虚构/获准脱敏数据；不接真实模型、通知、OA/出管或 T+，不触碰生产，不提交、不推送、不部署。不停止他人测试，不清理他人目录，不打印凭据或客户原件。
- 出管/OA 提供事实，平台负责核对、草稿、复核、交付和管理分析；T+ 是本试点选定的正式外部账务出口。已有 OA 事项不重复录入/审批，会计复核仍保留。
- 企业、账套、期间、对象 ID、来源版本与当前授权必须绑定。按钮显示不是授权；服务端仍逐次核验。复核责任、C01 覆盖证据、企业锁、独立复核后导出、费用与 attempt 防重发不能弱化。
- 未知、未汇总、加载、失败、确实为零分别表达；unknown 只查询/核查，不自动重发、重复提交或换幂等键。指派不授予权限。
- 所属单位与主要身份常显；当前办理客户/账套/期间另外明确。员工端只呈现完成任务所必需的企业与日期/业务月份，不强迫理解内部账套术语。
- 金额来自已验证服务或确定性计算；前端只按既有精度格式化，不自行重算会计结果、凑平或改变口径。内部记账、导出、T+接收/导入/过账、客户签收不合并成一个“已完成”。
- 范围切换、退出或撤权立即清除不再授权的数据、原件、选中集合和办理入口；不得等退场动画结束才清理。历史深链接不静默改指向最新对象/版本。
- 本批默认不改后端、数据库模式或业务策略。若发现本批真实入口所需的契约缺口，先写跨层失败测试并记录理由，只补最小必要扩展和 PG16/17 回归；新增持久关系才同步补恢复。不得因前端缺字段绕过复核或擅自给前序未完成业务造“成功接口”。必要迁移只能前向，先核并行编号，不改历史 SQL/checksum。

### 先红后绿、持续执行

每个子项执行：现状核对 → 写能证明用户问题的失败测试 → 运行记录失败断言 → 最小修复 → 成功、拒绝、竞态及浏览器回归 → 更新检查点。

- 已有测试能复现的先运行，不为凑红测故意破坏代码。纯视觉问题用可测布局/可访问性断言配截图，不以“类名存在”“源码包含字符串”替代真实表现。
- 过时断言只能在核实产品需求变化后改写；新的语义断言必须覆盖原有安全和办理目的。不得删失败用例、加 skip/xfail、关闭门禁、延长超时或放宽权限来换通过。
- 持续完成本批全部可独立执行的本地工作，不在只做样式、只测拒绝路径、只写报告时结束。定期更新 CHECKPOINT：已做项、准确下一步、失败原因、命令、产物、当前候选、自己启动的进程。
- 前序真实产品接口缺失属于工程依赖，不能用全量 mock 或静态卡片宣布功能完成。真实客户/T+资料缺失是外部待验：继续独立本地工作，但不冒充真实适配、真机或真实用户试点通过。

## L0｜依赖、范围与已有实现

读取 I/J/K 的验收、检查点、机器证据与组件说明；以当前代码核对，不拼各自历史绿灯。I/J/K 未完成的关键本地项要明确归属并最小修复/回归，不能把它们从总表删除。

范围：既有 AppPrimitives、AppDialogs、导航/抽屉/原件预览/助手、共享键盘与焦点工具、token及实际调用页；相关 CSS、测试、既有浏览器/体积门禁与文档。优先检查已有原生dialog、焦点恢复、isComposing、reduced-motion，不新建全局第二套弹层引擎。

## L1｜键盘、中文输入与弹层一致性

- 所有会触发业务/关闭的 Enter、Escape、快捷键入口先核对输入法组合态；候选词确认/取消不能变提交/丢弃表单。复用一个可测试的低层判断，不能用“一律禁用键盘”解决。
- 多层弹窗只处理最上层；弹层内的选择器/日历先处理自身Escape，不穿透关闭底层。
- 关闭返回正确触发点；触发点失效时到合理同页位置，不滚回页顶或跳到旧企业按钮。
- 遮罩关闭尊重未保存和处理中策略，拖选文字/拖动控件越过边界不误关；手机有明确关闭/返回入口，不只依赖手势。
- 视图切换、列表刷新不随意抢焦点；主动导航、错误定位、提交完成各按意图管理焦点。键盘焦点不隐藏在固定底栏后。

## L2｜统一反馈与微动效

- loading、空、失败、撤权、stale、unknown、成功分别呈现；仅一般成功可短暂toast，错误/冲突/unknown必须留在相关区域并有下一步。
- 操作按钮提交中保留尺寸与语义，防重复点击但不能冻结所有无关阅读操作；既有取消和状态查询仍可达。
- 骨架屏保持几何与加载说明，停止微光后仍显示未完成；不按动画循环次数推断完成，不提供虚假百分比。
- 优先沿用现有120/180ms动效token；确有需要再增加少量语义token并记录用途。禁止金额滚动、庆祝、视差、跟随光标、循环背景和整个工作区扫屏。
- 减少动态效果时取消不必要位移/缩放，结果、状态、焦点和可操作性保持；关闭动画不得阻止状态完成或锁住输入。
- 范围切换/撤权立即清除敏感内容，旧内容不淡出保留；记录中途关闭、快速重复开关、切页和请求取消的确定行为。
- 助手只显示服务器已确认的阶段和校验后事实。不能把未校验模型文字渐显到正式界面，不新增“思考链”展示，不改变只读和预算/attempt边界。

## L3｜跨浏览器、手机与同候选集成

复用现有配置选取 Chromium/Firefox/WebKit 核心用例；不为三个浏览器复制一套完整业务测试。构建预览与开发两种模式都验证，复用 scripts/run_e2e.mjs；不能为方便写第二套服务启动脚本，已有配置确需扩展则先测试。

同一候选必须跑：
- 员工/审批人/企业财务/制单会计/独立复核/负责人/只读的实际可办理边界；
- 两企业、连续两期（已有跨年夹具则复用）、多身份；企业切换、迟到响应、撤权、版本冲突、unknown；
- 新票据→审批/核验→移交→会计复核→受控导出；退回补件→重核验；
- 规费批次→差异→源行/原件→草稿→独立复核→T+文件/结果核查的本地已授权链；
- 待办直达、处理后返回、刷新/登录返回、多层后退前进；
- 大批次筛选/分页/合计、选中集合、长文本、原件面板和手机键盘遮挡；
- 月度服务单、交付/签收、报告下钻等受公共样式影响的既有关键页不退步。

真实外部 T+ 操作/真实通知不执行；本地替身验证明确标记。未完成的前序业务使相应链路保持未通过，不能用静态页面或直写数据库跳过办理。

| L01 | 中文选词Enter触发提交、Escape误关、输入中快捷键跳页：命令入口保护，正常非组合态仍可用 |
| L02 | 嵌套选择器关闭连带底层dialog；关闭焦点回错企业/页顶；拖选越界误关：逐层行为一致 |
