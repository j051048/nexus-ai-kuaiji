## V05 任务卡

`src/task-presentation.ts` 输出身份摘要、精确业务状态、负责人、下一步及打开入口文案。

- 身份摘要按服务端 `bucket` 与当前能力收窄；负责人字符串仅显示，不参与授权。
- 固定摘要为待我处理、等待处理、处理中、已完成、需要关注；取消额外明确显示已结束。
- 按 `kind + state` 解释业务事实，区分资料验收、迁移验收/接管、会计审核、导出、回执核验。
- 识别完成、草稿生成或移交完成不代表已审核、已导出或外部已接收。
- 未知结果先读取已有结果并核对回执，不能直接建议重发。
- 缺少权限资料、未知状态、过期阶段不沿旧 `action_label` 提示再次执行。
- 不增加网络请求、轮询、数据存储或变更 API；任务点击仍通过现有详情读取重检范围与授权。
- 保留原始 `data-state` 与专业状态说明；列表与表格均展示负责人、下一步，手机允许长文本换行。
