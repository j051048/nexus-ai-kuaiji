# FSC11：跨企业办理副驾、管理汇总与人效计量

前置FSC06；行业视图只启用已经验收的FSC07–10能力。完整读总工作令。复用现有assistant/routing、只读调查、ContextPack、fact_validation、H01/AG05/RSI、BusinessContextCard、FirmInsights、observability/closing和value。

## 实施

1. 围绕三个问题接通已有能力：“今天先处理什么”“哪些公司本月不能交付”“这笔差异的证据和处理人是谁”。只读取证，展示覆盖/未检查范围、来源版本及弃答原因；不要另造通用Agent循环。
2. 集团范围由服务端根据逐公司授权生成，不从用户提问/客户端company列表直接信任。权限或版本在检索、合并、发布、打开办理卡时都重查；只汇总可见事实，无权公司存在性与数量不泄露。
3. 办理卡只允许已注册动作，绑定对象、版本、企业、期间与返回来源。生成补件/导出准备等预览不等于已执行；人工确认仍走现有授权、复核、幂等、费用/attempt和unknown规则。
4. 管理汇总优先“5公司状态、异常、责任、期限”，逐项可下钻。收入、利润、资金、往来、库存只来自确定性权威服务；期间/制度/币种/确认状态不一致时不盲目相加。管理汇总明确非合并财报，指标缺失不补零。
5. 按FSC01口径补实际人效记录：对象/步骤的人工有效工时、外部等待、返工原因、异常处理、转移业务端工时；可抽样申报和校正，明确样本覆盖，不以在线时长推断工作量。
6. 成本分开确认/估算/unknown，覆盖模型、基础设施、通知及人工口径。把一次性培训/迁移工时和常态运营工时分别展示，不能为了好看的收益图删除任一项。

## 失败测试

- 提问中植入跨公司查询、假权限或财务指令；模型给出未注册操作/错误金额；分页混事实版本。
- 同名公司/项目混合、历史版本当当前、撤权后事件重放泄露；未检查范围被称“全部正常”。
- 点卡片自动审核/发送/签收；过期卡片照样执行；unknown费用或发送被当失败重试。
- 月度口径混合、重复退回扭曲比率、导出使已复核样本减少；缺数据被0填充，等待时间被计算为节省工时。
- 缺库存仍生成完整两金；管理汇总被标法定合并财报。

## 验收

复用固定分母任务级回放与独立holdout，覆盖五公司查询、正常/缺件/冲突/撤权/超预算/unknown/版本变化。关键错误或跨企业泄露一票否决，不用平均分抵消。PG16/17权限、事实绑定、费用attempt回归；桌面手机从助手卡片到真实办理再返回。全程FakeProvider，本轮不验证真实模型质量或声称已节省10人。
