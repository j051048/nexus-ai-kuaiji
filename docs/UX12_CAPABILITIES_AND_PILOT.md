## 真实试点沿用已有机制

复用 [B08 企业授权模板](B08_PILOT_TEMPLATE.md) 和现有客户人工投入页面，不新增角色、指标库或试点平台。建议先选择流程标准化、会计愿意双轨核对的少量企业；数量由人员与业务复杂度决定，不以未经测量的 5/20/200 家作为能力承诺。

开始前逐企业补齐：授权与保留期、稳定企业/账套/期间、政策和业务范围、独立复核人员、现行正式账本、通知及模型允许端点、原件清单与哈希、冻结候选和回退负责人。任一未完成保持 `not_started`；签字不得由开发人员或 AI 代填。单人办理明确标记为非独立复核，不能合并进独立复核样本。

连续两期复用同一业务主线：开账准备 → 员工提交/退回补件 → 部门/财务核验 → 会计制单/独立复核 → 正式记账 → 银行及子账核对 → 锁期/发布 → 冻结交付包 → 客户授权查看与签收。第二期期初从第一期期末承接；跨年、多个银行账户分别列样本。旧系统继续双轨，逐项核对差异；未核实的旧数据不通过改状态“补齐”。

## 量化方法（无样本保持未知）

| 指标 | 记录与分母 | 对照与验收 |
|---|---|---|
| 每户人工分钟 | 现有 human_work_sessions 有效心跳计时；固定企业、月份和活动类型 | 与同类工作人工基线配对；同时报告样本数、未计时比例及异常返工，不把缺样本填 0 |
| 员工录入时间 | 显式业务录入计时；从开始到提交，排除暂停与离线间隔 | 首次与复用用户分别展示 p50/p95；无关账套不得汇入企业会计统计 |
| 退回率 | 固定期间提交的独立事项；分子为其中至少一次被退回的事项 | 同时报告退回原因和再次提交次数，不能通过重复提交稀释分母 |
| 逾期率 | 到期且明确期限的事项；无期限单列为待安排 | 以已冻结期限为准；改期限保留历史，不以重新指派消除逾期 |
| 交付与签收 | 冻结 package_id/version/manifest；通道接受、送达、查看、签收各列 | 新旧包分别统计；unknown 单列，不能算失败后自动重发或算成功 |
| AI 辅助效果 | 获授权样本的来源/策略版本、人工采纳与修改、真实用量 | 复用 H01/AG05/RSI 分母与 holdout；真实调用须另行授权，费用未知不按免费 |

人工汇总使用受控导出或既有只读页面，固定抽样日期与来源 ID；不新增隐蔽用户行为采集。试点通过需业务负责人签收两期账务差异、实际用户可完成任务、重大阻断关闭，并核验同一候选远端 CI、恢复与发布检查。当前仅准备上述执行方法，**没有真实用户好评、节省分钟数或生产容量结论**。
