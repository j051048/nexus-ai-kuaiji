# 第十一阶段：复核包、自动续跑、规则治理与真实业务评测

本阶段面向 2–3 家企业的完整月度试点。后台继续生成未审草稿；会计明确复核后才可导出。所有新接口沿用当前身份、事务所、企业和账套授权，撤权后不能读取原预览、评测或恢复记录。

## 同类业务复核包

`/api/review/packages` 在服务端完成现有完整凭证校验，把所选待办按同一企业、物理账套、期间、业务类型、稳定往来方、处理依据版本和分录结构整理。不同企业不会共用一个复核包；只有原始名称而没有确认身份的事项逐张展示。聚合不隐藏金额、日期、税额、辅助项、证据或异常差异。

- `POST /api/review/packages`：`items[{book_id,draft_id,expected_version}]`、`idempotency_key`；最多 100 张。保存不可变预览，同一请求编号不能改选集。
- `GET /api/review/packages/{id}`：重新核验当前授权和完整事实，返回每组及逐笔 `ready/blocked/stale` 状态。草稿、证据、主数据、规则或期间改变后，旧检查不再可确认。
- `POST /api/review/packages/{id}/selection`：`draft_ids`、`idempotency_key`。只能选择原包中当前检查通过的凭证，追加子预览；阻断的同账套其他事项不被静默纳入。
- `POST /api/review/packages/{id}/confirm`：`idempotency_key`。真人先核对差异和原件；服务端逐笔再次核验，沿用现有逐账套原子审核与固定回执，审核不自动导出。

生成和选择使用同事务快照，后续读取及幂等重放重新校验；同一事务内复用刚完成的检查，避免立即重复执行全部校验。身份解析仅在当前事务内复用，不跨身份或权限变化缓存。合计使用整数分，可超过单笔金额上限，但单笔输入仍执行既有精确金额约束。

PG055 / SQLite040 的 `review_package_requests` 将请求、父子预览及精确选择关联。PostgreSQL FORCE RLS 限定原创建者当前完整复核范围，worker 无表读取权限；原生触发器核验请求哈希、父预览和冻结选集。展示内容和真实证据指纹一起比较，不能通过复制正确指纹并伪造分录得到审核。

## 条件自动续跑与后台耗时

企业自动续跑策略默认关闭，企业管理员明确启用后，后台分批检查已知阻断是否解除。恢复记录保留旧输入、新输入、恢复原因和任务换代依据；执行前仍重新核验原执行人的当前授权、业务映射、事实、期间、企业处理开关、队列容量及费用额度。

已发送但结果未知、人工修改、取消、已审核或来源失效的任务仍需要明确人工处置。独立核验完成的补件和服务配置恢复可按记录换代，不能把任意事实变化当作恢复理由。后台巡检有界且按企业轮转；全库并发两件、同企业一件和现有写协调锁继续保留。

持久分阶段记录用于跨 worker 观察依赖等待、可领取排队、领取或事务锁等待、模型调用、核验落库及 OCR 复用。统计是本产品记录的运行样本，不能当作供应商账单、所有用户总工时或生产容量认证。

接口及详细恢复条件见 [条件续跑与后台统计](STAGE11_QUEUE_AUTOMATION.md)，最终验证记录列出实际覆盖范围。

## 企业规则治理

新规则可以绑定本企业稳定往来方及经过独立审核的别名，旧规则保持原文精确匹配。主数据歧义、失效或跨企业身份不能匹配。相同语义的自动候选不反复创建；显式重复创建说明已有候选，不把新的审核样例偷偷并入其他规则。

发布前检查适用范围冲突及当前主数据、科目、辅助项和样例；影子回放只比较经过审核的证据，不审批草稿。清偿样例仍只作追溯证据。命中统计按实际生成的规则版本与最终会计处理对照，不能用“未记录修改”代替会计正确率。详见 [规则治理说明](STAGE11_RULE_GOVERNANCE.md)。

## 真实业务评测中心

`/api/books/{book_id}/quality` 提供当前账套的已审核候选、冻结标准、独立确认及有界评测。标准来自真实已审核凭证和可追溯原件，由另一名复核人员确认；模型输出本身不能证明标准正确。

评测重放规则、固定模板或指定版本的存量模型候选，保存金额、税额、往来方、分录和辅助项差异。不调用真实供应商，不修改业务事项或凭证，不执行审核或导出。没有候选或没有足够证据时分别计为未覆盖或未知，不强行计为成功。

`GET /api/books/{book_id}/quality/report` 按每种回放模式的最新有界运行，汇总月份和业务类型的通过、差异、未覆盖与失效样本。旧配置保留报告及版本归属，但当前一致比例返回未测量。账套人工时间和补件日历等待单独统计，无法分摊到业务类型的字段返回 `null`。真实供应商质量、客户 T+ 入账结果、整月人工收益及 200–500 家容量仍须独立试点验收。详见 [评测中心说明](STAGE11_QUALITY.md)。
