## 本轮落实的改良

| 优先级 | 本轮实际范围 |
| --- | --- |
| P0 正确性及验收 | 冲销付款不能新核销、资产历史更正阻断、范围/版本/撤权与数据库约束；同候选恢复及固定门禁 |
| P1 已有业务办理 | 往来详情、部分核销/撤销/原凭证、资产跨期计提与独立复核记账 |
| P2 使用路径及维护 | 月度服务单直达与刷新后返回、手机控件、连续 CI 接线、原预算及容量证据 |

这是经适用性评估后的续批收口，不代表原始任务书中的发票供应商、费标、差旅、语音等新增领域已经建设完成。

- **往来事项可以直接办理**：从四类账龄打开具体事项，核对正式收付款凭证后登记部分核销；撤销必须填写理由并保留原记录。余额、历史、来源与可用结算金额按企业、账套、期间绑定。返回保留截止日期、类型和定位。
- **防止重复或过期办理**：提交绑定服务端快照；并发办理只能接受一份有效预览。网络结果不明时不自动重发，先重新读取并由人核对。已冲销或调整的付款不再作为新的核销依据，直接写库也拒绝。
- **资产跨期沿用同一卡片**：同一长期账套可在后续期间生成计提草稿；前期草稿未处理、历史期间无权限、科目版本变化、历史计提已经冲销或调整时阻断并要求人工核对。三个月跨年计提的 3,333 + 3,333 + 3,334 分经独立复核、正式记账后与累计账面金额相符。
- **月度服务单串起办理**：复用现有月度服务单和正式账簿，在已有折叠区提供往来及计提入口；刷新后仍按原企业、账套、期间返回服务单。未新增首页模块。
- **持续验收**：复用 `dcp_reliability_gate.py` 增加 `finance` 固定用例集，并接入 Accounting foundation 的 PG16/17 矩阵。工作流接线不等于远端 CI 已执行。

## 保留边界

- 核销不生成第二张付款凭证；计提只生成草稿，仍须独立复核后正式记账。
- 更正历史计提后，本轮只阻断继续计提并要求人工核对；未实现完整资产处置、减值或自动重算历史。
- 发票查验供应商、企业费标、差旅审批及语音录入仍按原适用性评估单独确定需求，不用离线替身冒充上线能力。
- 真实客户两期试点、真实模型/通知、跨节点及生产对象存储负载均未验证。本地合成负载不能证明可承诺管理 200–500 家真实客户。
- 本轮不提交、不推送、不部署、不修改线上数据。
