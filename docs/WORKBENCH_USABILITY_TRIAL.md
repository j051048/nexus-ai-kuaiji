# 岗位界面独立试用记录

状态：**待实测**。本文件是执行步骤，不是已完成的验收证据。

使用获授权的隔离环境、虚构企业和票据；不要求真实财务数据、不自动发通知。记录候选版本、设备、浏览器、网络条件。观察员只读任务，不告诉参与者按钮位置；任何提示计入“求助”。

| 岗位 | 交给参与者的任务 | 正确完成的依据 |
| --- | --- | --- |
| 员工 | 提交一张 128.50 元虚构差旅票据 | 企业、日期、金额、用途正确；用户确认后提交一次；能找到进度 |
| 员工 | 找到被退回事项，补充缺少的原件再提交 | 看懂退回原因；保留原填写；没有新建重复事项 |
| 员工 | 上传中断后继续办理 | 找到错误和恢复入口；先核对最新草稿；原件和事项均无重复 |
| 企业财务 | 核对原件并将完整事项交给会计；另一事项退回补件 | 选对企业和事项；能说明下一位处理人；原记录可追溯 |
| 会计／复核员 | 从待办打开原件与分录，完成允许的复核并返回 | 原件、版本、金额相符；不自审；返回保留筛选和位置 |
| 事务所负责人 | 找到某客户本月卡点和负责人，查看明细后返回 | 搜索结果与全所汇总不混淆；能找到期限和下一步 |

每次记录：岗位、任务、设备、完成／未完成、总耗时、点击错路次数、求助次数、是否看懂状态、是否发生重复提交、参与者原话。失败时保留脱敏截图和具体步骤，不用平均分掩盖跨企业或重复写入问题。

真机追加检查：相机权限允许／拒绝、旋转屏幕、长企业名、系统键盘打开和收起、底部按钮可触达、弱网与切换后台后恢复、iOS Safari／Android 浏览器／微信内置浏览器。触屏、屏幕阅读器和硬件键盘按实际使用情况分别记录，不能用桌面模拟结果代替。

通过条件：关键任务可独立完成；未发生错企业、跳过复核、重复提交或丢失填写；失败提示能引导正确下一步。效率目标先记录首轮真实基线，再冻结阈值并复测，不凭本地自动化耗时承诺员工办理速度。
