## 验收覆盖

1. 另一企业持续持锁时，本企业开启未结、预览、确认、独立撤销均能完成。
2. 两个真实 PG 会话竞争同一预览/相同幂等键，只生成一条分配；响应丢失后重试不重复核销。
3. 同企业两份预览竞争不足余额，仅一份成功，无超额核销。
4. 两会话重复独立撤销只形成一条撤销，原记录保留，余额恢复后可重新分配。
5. 使用 `pg_blocking_pids` 确认真实锁等待，撤权先提交后，等待中的确认被拒绝。
6. 错企业、员工无权、已关闭期间、原生 SQL 越权均拒绝；事务回滚无部分分配。
7. `pg_locks` 验证声明企业范围使用共享兼容门，旧无范围调用保持全局排他锁。
8. 未复核不可导出，制单人不可独立复核本人待审版本，经另一人复核后导出成功。
9. 原有规则隔离、核销样例不可推广普通分类、规则不自动发布、费用及 attempt 离线契约继续通过。
