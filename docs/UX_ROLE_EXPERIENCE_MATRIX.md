# 角色体验与入口归并（UX01 基线）

日期：2026-10-19  
性质：展示契约；不改变服务端授权、账务状态或数据范围。

## 1. 四类工作空间

| 工作空间 | 包含角色 | 默认入口 | 说明 |
|---|---|---|---|
| 客户协作 | 员工、部门审批、企业财务、企业负责人、只读 | 客户门户首页 | 提交、补件、审批、核验、报告 |
| 会计作业 | 记账经办、会计复核 | `/workspace/home` 或复核页 | 异常、草稿、复核、交付 |
| 事务所管理 | 事务所负责人 | `/workspace/firm` | 客户组合、团队、交付风险 |
| 系统管理 | 管理员 | `/admin` | 企业开通、人员权限、运行 |

四类是呈现方式，不是新的授权系统；同一账号可切换视角，但服务端能力不变。

## 2. 角色—首页—导航—主要操作矩阵

| 展示身份 | 默认首页 | 一级导航（4–6） | 首要操作 |
|---|---|---|---|
| 普通员工 | 客户门户首页 | 首页、我的事项、资料、消息、报告 | 提交业务 |
| 部门审批人 | 客户门户待审批 | 待审批、部门事项、资料、消息 | 处理审批 |
| 企业财务 | 客户门户待核验 | 待核验、业务事项、资料、消息 | 核验并移交 |
| 企业负责人 | 客户门户企业首页 | 企业首页、报告、资料、消息 | 查看报告/确认 |
| 记账经办 | 内部今日工作 | 今日工作、客户事项、异常与补件、月度交付、资料 | 继续处理 |
| 会计复核 | 内部待复核 | 待复核、异常与补件、月度交付、资料 | 开始复核 |
| 事务所负责人 | 全所概览 | 全所概览、客户、团队与效率、交付 | 协调和分派 |
| 管理员 | `/admin` | 管理后台 | 管理企业与账号 |
| 只读成员 | 客户门户首页 | 首页、资料、报告 | 查看 |

客户端入口由 `clientPortalTabs(profile)` 生成；内部一级导航由 `primaryNav(role)` 生成。两者只读取服务端已返回的能力/身份，不新增权限。

## 3. 企业/账套/期间上下文

- 单企业用户：显示企业名称，不强制无意义选择器。
- 多企业用户：只列 `profile.companies`；每条任务保留企业/期间。
- 内部会计：显示事务所、企业、账套、期间。
- 事务所负责人：全所范围，不自动获得跨所财务数据。
- 管理员：系统范围；企业内操作仍需选定具体企业。
- 范围来自服务端 session/profile；浏览器字段不能赋权。

## 4. 入口归并

| 原入口 | 新入口 | 方式 |
|---|---|---|
| 我的待办、异常收件箱、异常与补件、票据核对异常 | 今日工作 | 分类/保存视图 |
| 客户月度进度、服务单、周期资料 | 月度交付 | 资料仍可从客户/待办直达 |
| 后台运行、票据处理任务 | 处理记录 | 进度/事项详情 |
| 运行可观测性、费用监控 | 管理后台 → 运行与用量 | 仅授权管理 |
| 人工投入、效率 | 负责人 → 团队与效率 | 仅负责人 |
| 客户开通、旧账迁移 | 新增客户/初始化 | 管理流程 |
| 规则、模板、科目、主数据 | 账套设置 | 内部会计 |
| 试点评测 | 授权内部入口 | 从日常导航移出 |

本轮 UX01 先完成角色矩阵、客户门户导航过滤和集中展示契约；UX02–UX05 的入口归并、同屏复核、客户流程、助手入口按批次继续，未在本文件声称完成。
