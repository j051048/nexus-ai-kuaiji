## 实现结果

### 待办与返回

- 待办继续先读取当前任务详情并实时核验授权，再打开确切事项、资料、补件、原件或凭证。
- 修复跳转时先写不带事项编号的地址、再设置事项造成目标清空的问题。办理跳转由既有路由同步器一次写入完整目标。
- 客户的识别待办回到对应业务原件；专业工作台保留原批次处理入口。
- 明确指向本人补件任务的客户入口复用现有补件详情，不因客户门户的页面白名单而退回首页；不增加客户的专业主导航或全所授权。
- 本次登录会话内保存待办的类型、企业、等待/处理分组、搜索、排序、页码、列表密度、滚动位置与原任务焦点。月度列表保存月份、搜索和页码。
- 提供返回待办、返回本月服务单及返回客户月度进度；浏览器返回也恢复原选择。

### 原记录附近的操作

- 业务事实之后集中放置关联凭证与事实修订入口，不再埋在页面底部。
- 依据已授权账套的企业、期间、编辑权限和开放状态收窄修订入口；已审核或已导出但仍可合法调整的记录继续走原独立修订流程。
- 原件预览按需调用原有授权 blob 读取；切换事项、身份、版本或授权失效后不复用旧原件。
- 关联凭证直接打开现有同屏复核，关闭后仍在原业务记录。未确认原件不能审核，打开页面不会自动导出。
- 从业务列表所选事项进入修订，返回时使用实际所选事项 ID 与范围；不依赖入口 URL 曾带有事项编号。
- 未提交内容仍需确认放弃；成功保存为待独立复核的申请不再误报未保存，原业务金额保持不变。

### 月度服务单

- 服务单提供准备资料、会计复核、核验交付三个办理入口，携带确切企业、账套与期间。
- 按已读取服务单权限控制入口；加载、保存、失权、范围错配及未保存编辑时禁止跳转。
- 每个阶段重读其授权数据，返回同一服务单，保留原月度列表选择。
- 清除上一任务的资料、事项、回执等叶子选择，避免进入另一服务单后带入旧任务 ID。
- 不新增进度统计查询，不伪造“资料齐全”“账已做完”或“交付完成”。

### 共享预览与手机

- 将原件预览的布局样式从同屏复核页移入原件组件自己的样式文件，修复手机首次独立打开预览时图片仍为原始 900px 宽的问题。
- 保留桌面与手机共享 token、预览尺寸、长文件名换行及触控尺寸。
- 客户补件详情增加适合客户门户的留白、输入字号及触控尺寸，不改变补件权限或审核条件。
- 为本月办理路径明确独立布局，避免手机端的全局 `nav` 样式把标题与步骤挤成两列；增加步骤在标题下方、手机列表有效宽度的浏览器断言。
