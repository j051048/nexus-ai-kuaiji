# FSC03：集团共享组织、职责与任务分工

完整读取总工作令和FSC01；正式办理复用FSC02已验证基础。只补共享中心的组织/能力投影和责任闭环，不另造权限引擎。

## 复用范围

accounting/access与access_policy、既有岗位模板/时限授权/部门审批、service_plans、execution/handoff、monthly、FirmCockpit/AccessManagement。

## 实施

1. 明确集团→五个独立核算主体→账套/期间关系。优先映射现有事务所/企业模型；若存在语义不匹配写设计决策，不能将不同公司合并为一个tenant规避授权。
2. 基于已有能力配置经办、资料协调、资金往来、独立复核、主管及企业提交/审批岗位。五人只是仿真编制，不硬编码五账号或五家上限。
3. 每个办理项有主责、候选处理人、替补、期限、来源对象与版本。指派不授权；接手前重新检查授权/职责冲突/有效期，缺人明确上报。
4. 记录负载、待办年龄和交接原因，支持按授权范围再分派；不得自动扩大权限、重试unknown或更换实际制单责任。
5. 页面持续显示单位、岗位、当前企业/期间。共享人员可切企业，客户员工不能看到其他企业名单或集团汇总。跨企业连续复核要显式显示每笔所属单位并刷新权限。

## 失败测试

- 集团viewer因进入汇总页自动获得export/review；指派给无权人员后可打开原件。
- 同账号兼岗后能审核自己制作的同版本；待审期间换岗位抹掉原制单责任。
- 临时授权到期、撤员或切企业后缓存/下载/后台任务仍泄露数据。
- 主责请假后任务丢失或复活旧审批；负载只按数量导致逾期待办被长期饥饿。
- 并发接手同一事项覆盖责任、重复办理；部门负责人通过集团搜索看到其他部门/公司材料。

## 验收

五个合成企业+五名共享人员+企业端提交者/审批者，逐岗浏览器权限矩阵；PG16/17真实RLS/动作权限及撤权竞态。模拟一人请假、月末任务集中和跨企业代办，始终保持责任可追溯且独立复核不被架空。
