# 第一批改进验收记录 · 2026-10-14

版本：0.16.0。使用本机 SQLite、临时 PostgreSQL 14、桌面及 390 px 手机浏览器；所有企业、人员、票据与凭证均为合成资料。

## 静态与升级检查

- 完整本机后端回归：1,539 项通过，507 项按测试环境条件跳过；PostgreSQL 用独立管理员、API 与 worker 连接另行运行。
- 完整独立 PostgreSQL 回归：516 项通过，1 项按测试条件跳过，未出现失败或初始化错误；包括新提交渠道、XML、评测、连接池及原有领域／权限／队列测试。
- 前端 32 个文件、269 项单元测试通过；TypeScript、ESLint、Prettier 通过。
- 完整浏览器端到端回归：54／54 通过，含本批新流程及原员工、批量复核、撤权、旧账迁移、对账、回执和导出流程。
- 生产构建通过；当前主入口约 598.82 kB（gzip 181.17 kB），仍有 Vite 的 500 kB 分块提示，后续可继续拆分依赖及首屏代码。本批未把组件拆分解释为已测得首屏性能提升。
- Python 应用、网关及维护脚本共 168 个文件通过 Ruff 格式与正确性检查。
- 全新 UTF-8 PostgreSQL 数据库显式执行 001–076 共 76 个迁移，76 个历史摘要校验通过；原 PostgreSQL 001–072 与 SQLite 001–056 迁移未修改。
- Vercel 配置通过官方 JSON Schema 校验；工作区回退只作用于 app，API 网关仍独立路由。
- API 与 worker 使用不同受限数据库账号；池测试覆盖单连接身份交替、回滚归还、超时、撤权、进程共享采样与启动失败释放。

## 业务与安全验证

- 无模型配置时，合成 EInvoice 0.3 XML 可上传、解析、逐字段采用、无部门直接提交、独立会计接收、后台生成草稿、复核与 CSV 导出。未审核导出、申请人自接收及申请人自审仍被拒绝。
- 金额矛盾、红字、未知版本、损坏 XML 及 DTD／实体等异常进入明确人工处理；保留原件、哈希、字段路径、事实版本与企业权限边界。
- 直接通道 PostgreSQL 原生写入测试拒绝自接收、伪造部门审批、旧提交快照和错误期间；部门审批、合法接收与事实修订保持可用。
- 固定集合覆盖独立标准确认、版本、幂等、同来源重复样本、跨账套／角色／费用范围、撤权、证据漂移、归档基线、未覆盖及退步阻断。未知结果重复操作保留同一请求键。
- 路由覆盖刷新、后退、直接打开复核链接、待办定位及未保存编辑拦截。复核界面保留手工原件确认，并检查桌面紧凑表格与手机无横向溢出。
- 企业处理开关和补件关闭使用数据库 UTC 时间触发恢复，覆盖 API 主机快 10 分钟的原生回归。

## 验收边界

这些结果验证本机实现与合成流程。未执行云端生产迁移或部署，未验证真实供应商收费调用、发票验签验真或真实企业完整月份。

XML 当前只明确支持已文档化的 EInvoice 0.3 蓝字格式；OFD、其他 XML／XBRL、PDF 内嵌数据仍需分别适配。评测比较固定标准上的归档结果与确定性回放，未使用过的新模型不能得到自动通过结论。本批保留全局写锁和总任务并发上限，连接池与观测不代表已证明可承载 200–500 家企业。
