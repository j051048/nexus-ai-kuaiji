## 第一批：受限 PG 可运行与验收门槛

- `handoff_tasks`、`tax_filings` 补齐最小 GRANT、强制 RLS、来源/企业/账套/身份约束；保留办理记录只追加，指派记录只允许留痕替代。
- 人工接手要求当前有效且独立的复核人员；不能伪造来源版本、摘要、创建人或跨企业绑定。
- 原生 SQL 等待写锁期间发生撤权的红测复现后，用前向迁移再次检查锁后的当前权限。
- DCP11 的取证保持只读事务；最终短写事务重检权限及事实后写审计。撤权或依据变化不发布旧事实。没有扩大助手工具集、启用模型或声称新增自主循环。
- 迁移失败只输出操作阶段、迁移号、异常类、SQLSTATE，隐藏 DSN、参数及驱动 DETAIL。
- 核销锁独立 gate 固定 17 个用例，DCP gate 固定 26 个用例。检查真实 PG16/17、受限角色、持久化设置、迁移一致性、完整用例身份及零跳过，绑定运行前后候选指纹。CI 两个矩阵版本均新增独立步骤，不修改 RSI/C01 原门槛。

## 第二批：锁期、开通与交付预检契约

- 服务层及数据库禁止控制科目、适用性和银行映射变更影响已锁期间；未锁的未来期间仍允许配置。最终锁期仍使用原有完整预检，不用局部显示结果替代。
- 开通清单读取权威的期间适用性历史，旧 `subledger_control_settings` 的单条状态不再冒充本期配置。
- 月度包预览复用正式包 readiness，选择当前有效、独立复核且已发布的报表；未发布或已失效的报表不再显示可办理。
- 办理日期校验真实日历日期与账套期间，数据库也拒绝绕过 API 的非法写入。

## 第三批：批量状态、幂等与恢复

- 仅允许未取消、尚未耗尽次数的失败项重试，不清零 attempt，不复活 cancelled；耗尽后明确转人工。
- 批量执行在真实业务写事务内核对存储的命令、企业、创建人、租约 token、attempt、期限及取消意图，覆盖开期、导出和包草稿关键写入。
- 导出预览集合/版本校验进入导出事务；已提交导出的重放读取冻结清单，不再因草稿已变成 exported 而误报冲突。
- 中断后先查已提交导出/包草稿，再结算任务；结果必须与冻结对象/版本一致。同键的其他导出不能误算本次成功。提交后收到取消按实际已提交结果留痕，不伪装成撤销。
- 过期租约不能迟到结算，取消后过期不重新领取；两会话竞争领取只取得一份任务。
- 本轮保留既有全局队列写锁，不据此声称完成企业分片或 200 家多 worker 容量验收。
