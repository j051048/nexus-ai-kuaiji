原则：

- 导航只反映能力，不作为授权；
- API/RLS/服务层逐次校验；
- 自审禁止；
- 管理员权限不替代业务复核；
- 助手/缓存/统计不跨企业。

## 4. 合成企业与隔离夹具设计

至少：

- `SYN-A` / `SYN-B`：同一事务所、不同企业；
- `SYN-C`：另一事务所；
- 每企业两个账套（含一个未授权账套）；
- 部门：业务部、财务部；
- 身份：员工 A/B、部门审批、客户财务、客户领导、主办会计、复核人、事务所管理员、技术管理员；
- 期间：2026-10、2026-11，另补年中/跨年样例；
- 原件：发票、银行流水、合同、工资/资产样例；
- 负向：跨企业 ID、跨账套、同企业未授权账套、撤权后旧请求。

夹具不包含真实客户资料；测试数据库与正常运行库分离。
