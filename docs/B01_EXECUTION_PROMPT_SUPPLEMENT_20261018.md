## 2. 八条必须补进执行词的硬约束

### A1 基线与非提交规则

见第 1 节。目的：避免执行 AI 看到已修复代码后重复改造，或把已提交内容当作未提交改动覆盖。

### A2 原件清单的发现机制

不能只靠人工枚举。要求：

- 全仓检索 `storage_key`、对象存储 `put/read`、附件表迁移，形成注册表。
- 注册表由代码单一维护；备份、校验、恢复共用。
- 新增附件表未登记时，测试必须失败。
- 至少覆盖：`business_attachments`、`case_attachments`、`intake_attachments`、`bank_import_files`、`migration_files`、`material_attachments`、`invoice_import_batches`、`upload_intents`。
- 不能把“表存在但没有行”当成已验证；每类至少一个虚构样本。

**执行词补句**：

> 以 `storage_key` 全仓检索建立唯一原件注册表；新增附件表未登记时，备份测试必须失败。备份、校验、恢复不得各自维护清单。

### A3 对象版本、所属范围与一致性边界

当前存储抽象不一定暴露对象版本。要求：

- 清单每条记录：原件标识、表名、所属 `firm_id/company_id`（可空）、`storage_key`、大小、SHA-256、`object_version`、`schema_version`。
- `object_version` 优先使用存储版本/ETag/Last-Modified；不支持时写 `null`，并明确“不是原子快照”。
- 数据库用可重复读快照导出；原件逐件读取、哈希校验；不得宣称数据库与对象存储原子一致。
- 交叉核对：数据库引用的每个原件都必须在清单中；清单中的每个原件都必须被数据库引用，或明确标记为“在途上传/未消费”。

**执行词补句**：

> 对象存储不支持版本号时，清单记录 `object_version=null` 与 ETag/Last-Modified；不得宣称原子快照。数据库用可重复读快照，原件逐件哈希校验并交叉核对。

### A4 恢复后的 worker 与外发禁用

不能只在报告里写“默认禁止”。要求：

- 恢复产物带 `serving_enabled=false` 或等价标记。
- 恢复环境启动时显式禁用队列外发、模型调用、邮件和外部系统提交。
- 在途任务、`sending`/未知结果任务先隔离核对；不得自动重试或伪造结果。
- 有测试证明恢复后无模型、无邮件、无外部调用。

**执行词补句**：

> 恢复环境必须显式禁用 worker 与外发，并有测试证明无模型、邮件、外部系统调用；在途/结果未知任务先隔离核对，不自动重试。

### A5 B01.3 审计字段与政策范围

原词要求“制单人、最后实质修改人、复核人及审核政策版本”，但当前模型没有完整字段。要求：

- 最小实现：复核人、审核政策版本写入审计；制单人/最后实质修改人从现有审计事件推导。
- 不新增第二/第三复核人；只保留现有“申请人≠复核人”。
- 不为历史数据伪造操作者或政策版本；缺失就标注缺失。
- 若需要新增列，先列为 B02 设计项，不在 B01 擅自扩表。

**执行词补句**：

> B01.3 只强制现有“申请人≠复核人”；不新增第二/第三复核人。复核人与审核政策版本写入审计；最后实质修改人若现模型没有，列为 B02 待办，不伪造历史。

### A6 B01.4 默认封禁必须是代码级

原词说“不能只改一个默认配置值”，但当前实现用 `ACCOUNTING_INGESTION_ENABLED=1` 即可启用。要求二选一：

- **A6a（推荐，封禁路线）**：路由在代码层不可用，环境变量只能关闭不能开启；启用必须改代码并重新评审。
- **A6b（完整路线）**：代码开关 + 独立环境授权 + 企业级 allowlist 三个条件同时满足才启用。

本轮没有明确接入需求，采用 A6a。

**执行词补句**：

> 默认封禁必须是代码级不可用；仅设置环境变量不能启用。若将来启用，至少需要代码开关与独立环境授权两个条件。

### A7 旧令牌 URL 与日志验证

要求：

- 旧 `/api/integrations/webhook/{token}` 路径必须不可用。
- 用虚构令牌请求旧路径，检查应用、网关、反向代理日志均无原始令牌。
- 拒绝请求不得创建 `ingestion_connections`、`ingestion_runs`、业务来源、任务或可审核记录。
- 202 只能表示 `received`；不得展示为已导入/已记账。

**执行词补句**：

> 用虚构令牌请求旧含令牌路径，检查应用/网关/反向代理日志均无原始令牌；拒绝请求不得创建任何业务记录。

### A8 未验证项的交付状态

要求：

- B01.3 无 PostgreSQL DSN 时，状态写“未验证”，不得写“已修复并验证”。
- B01.3 未验证不阻塞 B01.1/B01.2/B01.4 的本地验证，但 B01 整体不得宣称完成。
- 全量测试未跑时，不得写“全量通过”。

**执行词补句**：

> B01.3 无真实受限 PostgreSQL 时标为未验证；不阻塞其余三项，但 B01 整体不得宣称完成。
