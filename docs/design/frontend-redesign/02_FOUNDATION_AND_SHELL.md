# FE02：变量、标志、公共组件、壳层

先读 `00_EXECUTION_MASTER.md`。前置：FE01 完成且人已选定方向。本阶段开始修改生产代码。

线索文件：`index.html`、`src/tokens.css`、`src/styles.css`、`src/agent-shell.css`、`src/AppPrimitives.tsx`、`src/AuthScreen.tsx`、`src/AgentNavigation.tsx`、`src/ClientPortalShell.tsx`、`src/AdminWorkspace.tsx`、`src/AccountIdentity.tsx`。

背景数字（2026-11-16 审计）：样式约 27,000 行、79 个文件，约 1,740 种硬编码颜色，463 处 7–11px 字号；`Modal` 只被 5 个文件使用，另有 10 个文件自己实现弹层；全站约 962 个裸 `<button>`。本阶段不求一次清完，求建立基础并阻止新增。

## FE02-A  变量映射与防回退基线

**做法。**

1. 把选定方向的取值写入 `src/tokens.css`：画布与表面、文字三级、分割线、品牌与主操作、四种状态色（成功、待判断、阻断、未知）、字阶、间距、圆角、焦点环、两档动效时长。保持单一来源。已有变量改值，不另起同义变量；确需别名时注明迁移去向。
2. 输出"原型变量 → 生产变量"对照表，写入 `docs/design/frontend-redesign/TOKEN_MAP.md`。
3. 新增守卫测试（读源码文本，照仓库已有同类测试的写法）：统计每个 CSS 文件中十六进制颜色和小于 12px 字号的出现次数，写成基线文件；测试断言每个文件的次数不高于基线。后续模块清理后同步下调基线。`tokens.css` 自身除外。

**验收。** 第 5 节门槛通过；临时在任一 CSS 文件加一个十六进制颜色，守卫测试失败，撤掉后通过，把失败输出贴进状态文件。

## FE02-B  标志归一

**做法。**

1. 按 `BRAND_INVENTORY.md`，把标志做成一个组件，提供亮底、深底、单色三种用法和若干固定尺寸。所有出现位置改用它。
2. 产品名、当前身份、所属单位各有固定位置；客户单位名称不与产品标志混排。
3. 副标文案全站统一为一套。长单位名在窄屏有省略规则，完整名称可通过标题提示看到。
4. `index.html` 的 favicon 与 `theme-color` 同步。不新增图片文件，沿用现有资源或内联 SVG。

**验收。** 门槛通过；`e2e/tax-i-shell.spec.ts`、`e2e/v01-visual-foundation.spec.ts` 通过；390 与 1366 下登录页和三类壳层各截一张图。

## FE02-C  公共组件状态

**做法。**

1. 在 `src/AppPrimitives.tsx` 补一个 `Button` 组件：主、次、文本、危险四种，含悬停、键盘焦点、禁用、进行中状态。禁用时可带原因文字，并区分三类原因："没有权限""还缺资料""版本已过期"。
2. 核对并补齐已有的 `Modal`、`EmptyState`、`Spinner`、`PageControls`、`StatCard` 的状态样式，全部改用变量。
3. 新增加载、空、错误三种页面级状态的统一样式，三者视觉上可区分，错误带重试入口。
4. 做一个仅开发环境可访问的组件样板页，同屏展示上述组件的全部状态。不进入生产导航和首屏包。
5. **本模块不做全站替换。** 只把 FE02-B、FE02-D 涉及的文件迁到新组件。其余在 FE03–FE06 各自范围内迁移。

**验收。** 门槛通过；`src/visual-foundation.test.ts` 通过；样板页截图存档；`e2e/qa-accessibility.spec.ts` 本机能跑则跑。

## FE02-D  登录与壳层

**做法。**

1. 登录页：中文产品名和表单为主体。正常、失败、多因素验证三种状态都保持可用。
2. 三类壳层（事务所、客户端、管理端）：
   - 常用任务排在导航前部，设置与帮助留在原位置。
   - 页面标题在桌面和手机上各只出现一次。
   - 空间不足时优先保留单位、期间和主操作，其次才是辅助文案。
3. 移除 `BRAND_INVENTORY.md` 中登记的工作页标语式大标题，改为一行页面标题。**本模块只处理壳层自身和首页；各工作页的标语在对应阶段处理。**
4. 常驻的单位、身份、期间切换条由 OPT09-D 负责。它已存在时只调样式使之与壳层一致；不存在时为它预留位置，不自行实现。
5. 不改路由规则、导航权限、身份来源。

**验收。**

- 门槛通过。
- `e2e/role2-firm-period.spec.ts`、`e2e/v09-navigation-history.spec.ts`、`e2e/qa-accessibility.spec.ts` 通过。
- 新增或更新 Playwright 断言：每种角色进入后只有一个导航项高亮；375 宽下超长单位名不撑破顶栏；刷新、前进、后退后回到同一页面。
- 375、390、1366、1920 四个视口各截壳层一张。

## FE02-E  动效统一

**做法。**

1. 按 `MOTION.md`，把壳层、公共按钮、`Modal`、状态提示的过渡统一到两档时长变量。
2. 系统开启减少动态效果时全部即时完成。
3. 弹层：打开后焦点进入，Esc 关闭，关闭后焦点回到触发元素；快速连续开关不残留遮罩。
4. 成功提示只由服务端成功响应触发。

**验收。** 门槛通过；`e2e/reduced-motion.spec.ts` 通过；新增断言：快速开关弹层 10 次后页面上没有残留遮罩且焦点在触发按钮上。
