# FE05：五企工作台、账套工作区、批量、报表与交付

先读 `00_EXECUTION_MASTER.md`。前置：FE02，以及 `OPT_STATUS.md` 中 OPT09-C、OPT09-D 为"完成"。未完成则本阶段不开工。

线索文件：`src/FirmCockpit.tsx`、`src/FirmInbox.tsx`、`src/FirmInsights.tsx`、`src/BookWorkspaceShell.tsx`、`src/MonthlyClientWorkbench.tsx`、`src/MonthlyPackagePanel.tsx`、`src/FormalClosePanel.tsx`、`src/GlobalAccountingAssistant.tsx`，以及批量、税务、出租车相关页面。

业务契约、权限、数据完整性由 FSC 批次负责。本阶段只改入口和呈现。尚未接通的能力显示为真实的"暂不可用"或"待确认"，不做假的成功路径。五家单位用合成数据。

## FE05-A  五企工作台

**做法。**

1. 首屏是一张表：行是单位，列是当前卡点、截止日、处理人、状态。默认按"最需要处理"排序，排序依据来自接口已有字段。
2. 五种状态各有文字加图形：未开始、正常、有差异、待补件、结果待核查。
3. 尚未加载或尚未汇总的数字显示为"未加载"或"待核实"，**不显示为 0**。
4. 每个卡点可直达具体对象，返回后列表筛选和位置不变。
5. 只显示当前用户有权访问的单位。保留现有分页、非独立复核提示。
6. 跨单位汇总区域固定标注"管理汇总，非合并财务报表"。

**验收。** 门槛通过；`e2e/firm-operations.spec.ts`、`e2e/firm-insights.spec.ts` 通过；新增断言：未加载的指标不显示"0"；点击卡点进入的对象标识与该行一致；无权单位不出现在列表。1366 与 390 各截一张。

## FE05-B  账套工作区

**做法。**

1. 单位、账簿、期间、期间状态由 OPT09-D 的切换条承担。`BookWorkspaceShell` 中与之重复的范围显示、流程说明、宣传式眉题、重复统计全部收起或移除。
2. 范围变化时重新获取权威状态，旧数据立即清除。
3. 月结预检失败项逐条显示：原因、差额、责任人、去哪里改，并可直达。不出现"请返回首页查找"这类提示。
4. 财务报表（资产负债表、利润表）目前只在 `FormalClosePanel` 内。本模块不新增路由，只把它们的版式按 FE04-D 的账表样式统一。独立报表页和从报表行下钻到明细属于功能新增，记入"顺带发现"。

**验收。** 门槛通过；月结相关现有 e2e 用例通过；新增断言：预检失败项的链接指向对应对象；切换期间后旧期间的失败项不残留。

## FE05-C  批量办理

**做法。**

1. 批量栏显示：本次范围、目标版本、可办数量、不可办数量及原因。
2. 逐单位结果可展开，区分成功、跳过、失败、结果未知、审批已过期。
3. 能否重试沿用现有契约，不新增重试入口。
4. 切换筛选后已选项的处理（保留、解除或需重新确认）遵从现有行为，只把当前处于哪种情况显示清楚。
5. 批量开账若已由 OPT05-C 改为队列方式，则显示批次进度；否则保持现状。

**验收。** 门槛通过；`e2e/monthly-batch.spec.ts` 通过；用拦截制造部分成功和结果未知并断言各自的文字可见。

## FE05-D  报表、简报与交付

**做法。**

1. 报表版式：数字右对齐、弱分隔、分组标题。标清金额单位、会计期间、比较口径、覆盖的单位范围，以及数字是实际、估计还是未知。
2. 图表旁保留表格或进入明细的入口。图表在黑白打印下仍可区分（线型或图案，不只靠颜色）。
3. 月度交付包顶部显示：当前版本、发布状态、文件清单、可见范围、签收进度。保留历史版本入口。
4. 送达状态分五种呈现：通道已受理、已送达、已查看、已签收、结果未知。
5. 打印样式：黑白可读、跨页重复表头、页眉含单位和期间。正式导出仍走原流程，本模块不改。

**验收。** 门槛通过；`e2e/formal-books-monthly-package.spec.ts`、`e2e/stage17-monthly.spec.ts`、`e2e/monthly-briefing.spec.ts`、`e2e/n04-client-signing.spec.ts` 通过；用 Playwright 的打印媒体模拟截一张报表图；新增断言：打印媒体下表头存在且单位、期间可见。

## FE05-E  行业页与助手

**做法。**

1. 行业页：以出租车已启用的页面（成本、租赁、费率、资产等）为样板，统一区块标题、字段排布、差异显示、来源链接、当前可做的动作。其他行业页按 FSC 实际进度迁移，没做出来的不动。
2. 线索：`src/TaxFeeBatchPanel.tsx`、`src/FirmInsightsViews.tsx`、`src/TaxFPanel.tsx` 存在数百字符的超长行。只对你在本模块修改的文件运行 `npx prettier --write <文件>`，前后各跑一次类型检查。
3. 税务页中"人工办理的证据"和"官方结果"分区显示，不混在一起。
4. 助手的办理卡显示：结论、事实来源、未检查的范围、需要人接手的事项、打开原记录的入口。权限被撤销或数据失效时，相关卡片立即清除。不改助手的动作种类和确认机制。

**验收。** 门槛通过；`e2e/tax06-fees.spec.ts`、`e2e/assistant-delivery-pages.spec.ts` 通过；出租车样板页 1366 与 390 各截一张。

## 阶段出口：真实链路

用本地合成数据按已实现的路径跑一次：月结预检阻断 → 处理 → 复核 → 报表或可导出 → 交付包 → 客户签收。旧版本、撤权、错误回执各一条反例。某一环只能用合成方式验证时，写明真实边界在哪里。
