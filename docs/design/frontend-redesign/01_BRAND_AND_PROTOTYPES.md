# FE01：基线、标志盘点、方向原型

先读 `00_EXECUTION_MASTER.md`。无前置。**本阶段不修改 `src/` 下任何文件。** 产物是截图、盘点表和独立的静态原型，供人选定方向。

原型放在 `docs/design/frontend-redesign/prototypes/`，每个原型是一个可直接用浏览器打开的 HTML 文件加一份共用 CSS，不依赖构建、不引用外链。原型里的企业、凭证、人名、金额全部虚构。

## FE01-A  同候选基线截图

**做法。**

1. 用现有本地启动方式和合成数据，按现有 Playwright 配置写一个只截图不断言的脚本（放 `tmp_test/` 下，不进 `e2e/`）。
2. 截以下页面，桌面 1366×768 和手机 390×844 各一张：登录页、员工首页、会计复核队列、同屏复核抽屉、正式账簿余额表、负责人全所概览、月度交付、客户端首页。
3. 每张图的文件名包含角色、页面、视口。

**验收。** 状态文件列出截图路径清单。截不到的页面写明原因。

## FE01-B  标志与品牌用法盘点

**做法。** 只读盘点，输出一张表：

1. 标志出现的每个位置：`index.html` 的 favicon 与 `theme-color`、`src/AuthScreen.tsx`、`src/AgentNavigation.tsx`、`src/ClientPortalShell.tsx`、`src/AdminWorkspace.tsx`，以及搜索到的其他位置。记录图形来源（内联 SVG 还是文件）、尺寸、颜色、旁边的中文名和副标文案。
2. 不一致之处：同一标志的不同画法、不同副标、不同字号。
3. 长单位名称在侧栏和手机顶栏被挤压或截断的实例。
4. 工作页顶部的标语式大标题清单（如"每一笔，都有据可循。"），记录所在组件和占用高度。

**验收。** 盘点表写入 `docs/design/frontend-redesign/BRAND_INVENTORY.md`。

## FE01-C  两个方向的同题原型

两个方向用**完全相同**的数据、字段、按钮文案和操作流程，只在视觉上不同。不重画标志：两个方向都用现有图形和"衡账"二字，只调整比例、间距和对齐。

| 维度 | A · 账页 | B · 中性工作台 |
| --- | --- | --- |
| 底色 | 暖灰纸面配白色工作面 | 冷灰白 |
| 品牌绿 | 用于品牌区和主操作 | 只用于当前项和主操作 |
| 分隔 | 细栏线，表格有清晰页眉和小结行 | 浅分隔，靠对齐和留白 |
| 字体 | 系统中文无衬线；仅登录页标题可用系统自带宋体 | 系统中文无衬线贯穿 |

颜色取值从 `src/tokens.css` 和 `docs/design/open-design/hengzhang/DESIGN.md` 现有值出发，需要新值时在原型 CSS 顶部以变量集中声明并注明用途。

**每个方向做四屏：**

1. 登录页（1366 宽）。
2. 员工交票与补件（390 宽）：有一条被退回待补件的事项。
3. 会计同屏复核（1366 宽）：左侧凭证事实与差异，右侧原件占位；队列为高密度表格，至少 15 行，含三种风险分档和借贷不平的一行。
4. 负责人五企业卡点（1366 宽）：五家单位含未开始、正常、有差异、待补件、结果待核查五种状态。

**每屏必须体现：**

- 顶部固定显示当前单位、身份、期间。
- 金额右对齐、等宽数字、千分位、两位小数；负数与零、空值可区分。
- 状态用文字加图形表达，不只靠颜色。
- 没有标语式大标题。

**验收。**

- 八个 HTML 文件能直接打开，无控制台报错，无外链请求。
- 每个文件 1366 或 390 视口下截图存档。
- 用脚本计算每个方向正文、次要文字、状态文字与其背景的对比度，列表写入状态文件；正文不低于 4.5:1。
- 复核屏 1366×768 首屏可见队列行数不少于 12，在状态文件写出实际行数。

## FE01-D  数字样张与动效表

**数字样张。** 一个 HTML 文件，用两个方向的样式各渲染一组：`¥`、`0` 与 `O`、`1` 与 `l`、负数、千分位、九位以上大额、小数、空与零；20 个字以上的单位全称；含生僻字的名称。分别在页标题、正文、表格、金额列四种字号下展示。同时列出 Windows、macOS、Android、iOS 下系统字栈各自会落到的字体名（按字栈声明推断并注明是推断）。

**动效表。** 写入 `docs/design/frontend-redesign/MOTION.md`，每行包含：场景、触发、视觉变化、时长、被打断时的行为、系统开启减少动态效果时的行为。以现有 `120ms` 和 `180ms` 为准，不新增时长档位。至少覆盖：

| 场景 | 要求 |
| --- | --- |
| 按压、行聚焦、选中 | 颜色或描边变化，不位移。键盘焦点立即可见 |
| 抽屉、原件查看、分步 | 短距淡入。打开即可操作，关闭归还焦点。快速开关只保留最后一次意图 |
| 加载、刷新、切换单位 | 预留尺寸防跳动。切换单位或撤权时旧内容立即清除，不做渐隐 |
| 成功、错误、结果未知 | 由服务端真实结果触发。错误和未知持续显示。金额直接更新，不做数字滚动 |
| 减少动态效果 | 全部即时完成，焦点顺序不变 |

**验收。** 两个文件存在；动效表每一行都能对应到现有 CSS 中的一处实现或标注"待 FE02-E 实现"。
