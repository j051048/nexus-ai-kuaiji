先读 `00_EXECUTION_MASTER.md`。前置：FE02，以及 `OPT_STATUS.md` 中 OPT08-A、B、C、D 和 OPT09-A、B、E 均为"完成"。**任一未完成则本阶段不开工。**

线索文件：`src/ReviewWorkbench.tsx`、`src/InlineReviewDrawer.tsx`、`src/JournalEntryGrid.tsx`、`src/BusinessWorkspace.tsx`、`src/BusinessOriginalPreview.tsx`、`src/FormalBooksWorkbench.tsx`。

分工再强调一次：队列表格化、风险分档、金额模块、科目选择器、键盘导航、确认对话框是 OPT 的产物。本阶段**不改它们的行为、数据来源和键盘规则**，只做版式、层级、状态呈现，以及 OPT 没有覆盖的同屏核对布局和原件查看。审核门槛（已确认、借贷平衡、证据齐全、无未保存修改）和制单与复核分离一律不动。

## FE04-A  复核队列的版式

**做法。**

1. 在 OPT09-B 的表格上调整：列顺序为风险分档、单位与期间、事项、金额或差额、需谁行动、状态。会计默认紧凑密度。
2. 待审、待补、过期、阻断四种状态各有专属的文字加图形。
3. 筛选条收成一行。不新增摘要卡片。
4. 切换单位或期间后，只显示新范围的数据，旧行立即清除。
5. 该页样式中的硬编码颜色和小字号全部改为变量，下调 FE02-A 的守卫基线。

**验收。** 门槛通过；OPT09-B 的"1366×768 首屏不少于 12 行"用例仍通过；`e2e/review-focus.spec.ts`、`e2e/tax-j-selection.spec.ts` 通过；1366 与 390 各截一张。

## FE04-B  同屏核对布局

**做法。**

1. 桌面（宽度不小于 1100px）：稳定的左右两栏。左栏依次是单位与期间、凭证事实、差异、复核条件与下一步；右栏是原件。两栏各自滚动，拖动原件不带动分录。
2. 有差异时，差异在对应行原位显示，用文字写明方向、来源值、申报值，不只靠颜色。
3. 复核条件（OPT09-A 的原因列表、缺失证据、借贷差额）固定在左栏顶部，不折叠。
4. 手机：拆成"凭证与差异""原件"两个明确入口，长原件可进入全屏查看器。
5. 打开原件再返回后，保持：选中的分录、列表筛选、光标位置、滚动位置。
6. 详情区展示依据、版本和变更记录的入口，沿用现有数据。

**验收。**

- 门槛通过；`e2e/stage12-inline-review.spec.ts`、`e2e/v03-entry-review.spec.ts`、`src/entry-review-visual.test.ts` 通过。
- 新增断言：打开原件并关闭后，焦点回到原分录行且滚动位置不变；有差异的样例在首屏可见差异文字；无差异样例不显示差异区。
- 有差异、无差异两个样例，1366 与 390 各截一张。

## FE04-C  原件查看

**做法。**

1. 原件加载中、加载失败、无权限、文件已被替换（版本变化）四种状态分别呈现；失败可重试。
2. 切换单位、关闭抽屉、打开另一张凭证时，上一份原件立即清除，迟到的旧响应不显示。
3. 多份原件时可切换，显示当前是第几份及名称。
4. 下载入口按服务端授权显示。不改下载接口。

**验收。** 门槛通过；用 Playwright 拦截制造原件加载失败、403、迟到响应并断言；跨单位附件不可见的现有用例通过。

## FE04-D  账表与分录的视觉

**做法。**

1. `FormalBooksWorkbench` 余额表和明细、`JournalEntryGrid`、抽屉内分录：统一表头、行高、斑马或分隔线、合计行样式。金额列一律使用 `MoneyCell`。
2. 表头吸顶；横向滚动时首列（科目或摘要）固定。
3. 借贷差额不为零时，合计行有持续可见的提示。金额变化直接更新，不做数字动画。
4. `FormalBooksWorkbench` 表格上方的多层折叠说明和重复工具栏合并精简，表格在 1366×768 首屏可见。
5. 把时间戳显示为本地可读格式；内部摘要值和标识不直接展示给用户（线索：`src/ClosingWorkbench.tsx` 中"关闭时间"和"快照"的显示）。完整值可通过"复制"或标题提示取得。
6. 涉及文件的硬编码颜色和小字号改为变量，下调守卫基线。

**验收。**

- 门槛通过；`e2e/tax05-large-voucher.spec.ts` 通过（515 与 516 行大凭证不卡顿、不错位）。
- 新增断言：余额表 1366×768 首屏可见数据行不少于 10；负数、零、空值显示各不相同；20 字以上科目名不撑破列宽。
- 大凭证和普通凭证各截一张。

## FE04-E  焦点与输入细节

**做法。**

1. 抽屉打开、切换上下一张时使用 FE02-E 的过渡；焦点不因列表重排跳到别的凭证。
2. 中文输入法组合输入期间，回车不触发提交或跳格。
3. 同一请求重复点击只发送一次。
4. 退款等负数金额样例显示正确。

**验收。** 门槛通过；新增 Playwright 断言：组合输入状态下回车不触发保存；连点审核按钮只产生一次请求；`e2e/qa-accessibility.spec.ts`、`e2e/reduced-motion.spec.ts` 通过。

## 阶段出口：真实链路

用本地合成数据和真实本地接口跑通一次：员工提交 → 企业财务核验 → 会计查看原件 → 独立复核 → 进入可导出状态。再跑反例各一：本人复核自己的单、旧版本、已锁期间、权限被撤销、跨单位附件。全部沿用现有用例，不为通过而修改后端。涉及复核与导出的后端用例复跑；PG 本机无库时写"PG 未验证"。
