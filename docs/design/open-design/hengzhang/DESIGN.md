# 衡账设计系统

## 视觉气质

面向长时间办理财务工作的用户。把页面当作一张有清晰栏线的工作表。暖灰背景区分页面层次，白底承载数据和编辑，深绿引导主操作。用克制的圆角、清晰的基线和适量留白建立视觉秩序。偏深的文字比装饰标签更适合重要信息。登录页可用一处简洁的账页式品牌构图，办理页用原件缩略和业务状态提供视觉线索。

## 色彩和图标

| 角色 | 值 | 用途 |
| --- | --- | --- |
| 背景 | `#F5F4EF` | 页面画布 |
| 白色工作区 | `#FFFFFF` | 表单、表格、原件和详情 |
| 暖层 | `#F0F1EA` | 筛选分组、弱选中背景 |
| 深墨 | `#202B25` | 标题、金额、关键正文 |
| 次文字 | `#46584E`、`#55665B` | 表头、辅助说明和文字链接旁说明 |
| 品牌绿 | `#245441` | 主按钮和当前入口，主按钮文字白色 |
| 正常完成 | `#276344` | 完成与已核验，配状态名称 |
| 待判断 | `#805415` | 材料未齐、差异、结果待核查 |
| 阻断 | `#9C342D` | 确实阻断、失败和必要的破坏性动作 |

采用同一组线性图标，常用 16px/20px，触控区域按实际控件尺寸计算。可点击图标有可访问名称。状态由文字和图标表达，色调辅助识别。表格分隔边线轻，输入边界、选中与焦点更清楚。

## 字体和数字

主界面先用现有中文系统字栈，主要是 HarmonyOS Sans SC、苹方、微软雅黑、Noto Sans CJK SC。中文正文 14–16px，关键字段与手机输入 16px，表注 12px，表头和普通列表 13–14px，分组 18–20px，页标题 26–28px。字重以 400/600 为主，正常行高约 1.55，标题约 1.3。品牌标题可以试一处本机宋体，先评审跨系统回退是否稳定。财务金额、日期和验证码仍以可读性为先。

金额与数量用同一数字族的等宽数字特性 `tabular-nums`，金额单列右对齐，保留千分位、负号、单位和精度。检查所选中文/西文回退字体是否真的支持数字对齐。必要时局部引入授权的数字子集并测体积。空值使用“未核实”或“暂不可用”，按业务语义保留明确的零。

## 布局与密度

以 4px 为节奏，控件内部 8–12px，组内 16px，组间 24–32px。现有 6/10/14px 圆角优先用于控件/容器/弹层，胶囊用于小状态。桌面员工及客户任务行约 48px，会计桌面表格行约 38–42px。手机主动作与触控目标按至少 44px 设计。

同一页只保留一个主标题，账号所属单位/角色和当前企业/期间可辨认。正文第一段放当前任务或差异。内嵌信息少用多层卡片，列表和凭证用清晰分隔线。证据在足够宽的视口并排，窄屏提供标签切换或完整查看器。依据内容决定断点，复用现有断点并覆盖选定视口。

## 组件与交互

- 待办行具备事项、单位、金额或期限、具体状态、负责人和一个当前可执行动作。保留准确返回来源。
- 输入框有可见标签、单位、可纠正的帮助和行内错误。提交失败保留已输入值。打开原件前重查其当前作用域。
- 列表筛选可发现，表头、分页、合计及选中范围彼此清楚。批量确认同时展示本次范围、结果可能部分成功的提示和操作依据。
- 复核显示原件、金额差异、来源和版本、办理政策及下一步。主操作与次操作区分，退回、补件等项保持易找。
- 反馈文案给事实和下一步。例如“这张票的金额与原件差 ¥20.00。先核对原件，再提交复核”。结果未知时使用持续可见的状态和人工核查入口。

## 动效与反馈

沿用 120ms 快速状态、180ms 普通切换，缓动 `cubic-bezier(0.2, 0, 0, 1)`。按钮、Tab 选中和状态切换短而明确。抽屉以约 180ms 的轻位移/淡入表达来源，打开后键盘焦点立即可用。首次加载使用稳定尺寸的骨架，慢请求显示具体状态文字。保存或提交的成功提示可以淡入，错误、阻断和未知结果留在对应对象处。

减少动态效果时使用即时切换、静态进度和可读状态。金额、余额与差额直接显示。正式确认的反馈与服务端状态绑定，视觉过渡不延迟受理结果或键盘操作。

## 可访问性

正文方案检查前景/背景对比度至少 4.5:1，大字至少 3:1，控件关键边界和焦点在实际背景上单独测量。手机输入 16px并测试软键盘，吸底操作从安全区计算。键盘可到达行入口、原件、次操作和提交。原生弹窗保持焦点归还，逐层处理 Escape。动效尊重系统设置，页面放大后保留关键状态和动作。

## 图表、打印与资料

图例与关键数值展示口径、日期和单位，经营汇总可回到企业或来源。颜色使用绿、墨、灰为主，差异保留方向和文字，待核实金额保留占位说明。打印视图使用有层次的黑白版式，表头随页可读，输出与冻结版本一致。票据原件维持原比例，可缩放、翻页与定位。

## 工程交接

此目录的 `tokens.css` 供 Open Design 原型使用。实施阶段把核定值映射到项目既有 `src/tokens.css`，例如 `--bg` 对应画布、`--fg` 对应正文、`--accent` 对应主操作。一次迁移一个已有组件或路由，关联旧截图、正常/异常样板及现有验证。原型使用虚构数据。阶段验收由真实本地业务和浏览器测试提供。
