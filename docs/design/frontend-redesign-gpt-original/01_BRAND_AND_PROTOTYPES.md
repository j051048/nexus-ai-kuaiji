# 阶段 01｜品牌方向、视觉原型与动效规范

完整继承 [执行总令](00_EXECUTION_MASTER.md)。本阶段交付可评审的本地设计样例、品牌规范与实施映射。先定方向和交互，再把值写入生产 token。

## 基线与必做原型

- 核对登录 `AuthScreen.tsx`、事务所 `AgentNavigation.tsx`、客户端 `ClientPortalShell.tsx`、管理端 `AdminWorkspace.tsx` 的标志、中文名称、副标、颜色和图标。当前标志用法与小字号副标不一致，核查现有图形资产、图标导入与 `index.html` 的 favicon。标记长企业名称和移动壳层受挤压的例子。
- 保留 [历史截图](../../ux-screenshots/accounting-desktop.png) 与 [员工历史截图](../../ux-screenshots/client-mobile.png) 作为预期问题参考。重新采五角色同候选基线。截图上区分账号所属单位、当前办理企业、对象/账期。
- 同数据、同角色、同工作任务和尺寸出两个品牌方向的原型。至少提供登录、390px 员工交票/补件、1366px 会计同屏复核、1366px 负责人五企业卡点。选定方向的三条业务路径做可点及可返回的原型，覆盖一条失败处理。登录样板验证品牌和登录可读性即可。

## 两套方向

| 维度 | A · 现代账页（默认） | B · 中性工作台 |
| --- | --- | --- |
| 标识 | 以现有几何图形和中文“衡账”做字标/小标组合。梳理比例、间距与光学对齐，品牌识别来自标题节奏和像账页的对齐结构 | 中文无衬线字标与单色小标，标志体量轻，把辨识度放在数字栅格和稳定的任务区 |
| 颜色 | 保留品牌绿 `#245441`，暖灰纸面 `#F5F4EF`，白色工作面、墨色文字；小范围深绿用于品牌区和主动作 | 以冷灰白和中性墨为主，品牌绿只用于当前、主操作和可交互强调；状态色单独绑定 |
| 字体 | 中文无衬线 UI + 少量中文宋体品牌标题样张，保留经测量的系统回退 | 中文无衬线贯穿，以字号、字重、网格、数字对齐产生主次 |
| 版式 | 细栏线、纸面边距、首屏一个任务焦点，表格有清晰页眉和小结 | 浅分隔、对齐紧凑、增加内容区留白，任务与状态位置简单固定 |
| 品牌媒介 | 登录和空白引导可用一处原创账页构图或脱敏样张。办理页的票据缩略来自实际原件 | 登录以简洁版式和一个品牌图形开始。管理界面主要依靠列线、对齐和留白 |

两个方向共用业务字段、按钮和状态文案，避免用不同操作流程替某个色系加分。主标、副标、产品标识和客户单位标识有明确位置，提供亮底、深底和黑白打印样张。标识需在 16/32px 页签尺寸、44px 触控容器和桌面侧栏经审查。形成留白、最小尺寸、正反色、文件来源/授权和可用场景的简明规范。品牌资产以可维护、可授权为准。先比较现有标志收敛与微调样张，再决定是否有重画价值。

## 美学与阅读规格

1. 每页记录主视线起点、第二信息和可移到详情的内容。用网格和间距的层级明确“企业与期间→任务/金额→状态或差异→下一步”。控制状态徽标密度、卡片层数、描边、圆角和阴影的用量。桌面会计看高密度列，员工与客户看更宽松的步骤。
2. 以项目现有 CJK 系统字栈起步。制作 400/600 字重、页标题/正文/标签/表格/金额的真实文本样张。中文长企业名和罕见字、`¥`、`0/O`、`1/l`、负数、千分位、小数、空与 0 均检查。测试回退字体实际数字等宽、截断、对齐与窄屏。可选一处宋体样张用于品牌大字，正文、字段和账表先通过高密度可读性。任何额外字体先核授权和首屏字节数，再决定是否采用。生产同一业务数据格式化沿用原契约。
3. 图标沿用现有图标库，用统一视觉重量和光学间距。待办、需要补件、存在差异、正式阻断、结果未知和已完成分别以短文字与辅助图形表达。白面和暖面上的文本、焦点、控件和状态实际测量。错误和金额差异优先保留原位置。
4. 把图表及数据密度纳入视觉样板。负责人正常行保留弱色，有卡点的行有清晰状态、原因及负责人。显示含义、口径、单位、期间及未知。图表可回到明细，黑白打印保持区分。

## 动效分镜和验收

为每种动效提交“触发、视觉变化、业务语义、时长和缓动、打断/反向、减少动态效果、测试”的表，至少包含以下项。以现有 `120ms` / `180ms` 为起点，时长按浏览器实测调整，使用现有 CSS 和原生控件。

| 场景 | 设计要求 |
| --- | --- |
| 按压、行聚焦、选中 | 约 120ms 颜色或轻微描边变化。键盘焦点即时可见。避免位移造成误点 |
| 抽屉、原件、分步 | 约 180ms 短距淡入/位置过渡。打开时互动与焦点立即可用，关闭归还焦点。快速开关只保留最后意图 |
| 加载、刷新、范围更换 | 预留尺寸，短请求避免骨架闪烁。慢加载说明正在获取何物。同范围刷新可保留安全旧数据并标识，换企业或撤权立即清除，旧内容不以渐隐留在屏幕 |
| 成功、错误、未知 | 反馈取自真实结算状态。保存成功可短淡入，错误/未知持续显示原因和可执行核查。金额、借贷差额和账期直接更新，状态无抖动和庆祝 |
| 降级 | 系统减少动态效果时即时完成或静态反馈，键盘语义和可达顺序不变。后台/切页暂停多余连续动画 |

录制桌面/手机各一段：进待办、打开证据、失败恢复、返回、快速切两家公司。并排比较默认和减少动态效果。验收不能出现遮挡按钮、二次提交、旧企业内容残留、金额布局跳动或读屏重复播报。当前录屏未生成时标记待制作。

## 产物与通过条件

- 两套同题原型对照、选定方向的三个可操作样板、一页品牌资产用法、字体与数字样张、颜色与状态对照、动效表及关键录屏。
- 评审逐项记录品牌识别和一致性、信息阅读顺序、任务可完成性、误触/错范围、对比度/键盘、反馈时机。任务失效或权限风险先修；然后比较美学。保留选向理由和看过的人员/样本类型，不以 AI 评分代替实际试用。未收到偏好时，满足门槛优先采用 A 作为本地初版。
- 齐备后更新视觉规范与设计包版本映射，项目生产 CSS 的具体变更由阶段 02 完成。记录 Open Design 实际使用证据或本地浏览器样板路径。
