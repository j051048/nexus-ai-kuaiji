# 阶段 05｜共享中心、账套、月结与交付

完整继承 [执行总令](00_EXECUTION_MASTER.md)。前置为阶段 02 视觉基础及阶段 03、04 的可复验业务链。五家企业使用合成数据。仅把已接通业务放进成功路径，待实现业务保持真实的不可用或待确认状态。

## 范围

按归属核对 `FirmCockpit.tsx`、`FirmInbox.tsx`、`FirmInsights.tsx`、`BookWorkspaceShell.tsx`、`MonthlyClientWorkbench.tsx`、`MonthlyPackagePanel.tsx`、`GlobalAccountingAssistant.tsx` 及已存在的批量、税务、出租车与行业页。FSC02/06/12–17 负责业务契约、权限和数据完整性，本阶段以既有入口与呈现改良为主。若关键能力未接通，说明所属任务及依赖，继续复用当前可用路径。

## 依次改造

1. **五企业工作台。** 让负责人在首屏看到公司、当前卡点、截止期和处理人。默认按可行动程度排序，明确哪些数据未加载或待核实。每条风险直达其原对象，回到原列表和筛选。保留现有企业分页、非独立复核提示和逐企业授权。在设计评审中记录负责人能否快速找到“最先处理哪家”和对应实操入口。
2. **账套工作区。** 把企业、账簿、期间、状态收成可复用的范围条，收起与当前任务重复的流程说明、宣传眉题和统计。会计默认紧凑；范围变化时重新取权威状态。月结失败项显示明确原因、差额、责任与改正路径，避免“返回首页自行找”。
3. **批量办理与接手。** 批量栏显示本次范围、目标版本、通过及不可办对象。有逐企业结果时允许看来源和处理记录。什么时候可重试沿用现有契约。结果未知、部分成功、审批过期和已完成分别呈现。切换筛选后的旧选择冻结、解除或重新确认应遵从已有行为。记录接手不产生额外权限。
4. **报表、简报与交付。** 用数字对齐、弱分隔和分组标题形成报告版式。标清金额单位、会计期间、比较口径、覆盖范围、实际/估计/未知。图表重点提示差异来源，保留表格或下钻入口。月度包顶层显示当前版本、发布状态、文件、权限及签收进度，保留历史。通道受理、已送达、已查看、已签收和结果未知各有不同文案与图形。打印样板测黑白、跨页表头、金额与期间，正式导出仍从原流程办理。
5. **行业与助手。** 先用出租车成本/租赁/费率/资产等实际已启用页作视觉样板，再按 FSC 真实进度迁移其他行业。统一区块、字段、差异、来源和当前动作。税务人工办理证据与官方结果分开。助手用现有办理卡说明结论、事实来源、未检查范围、人工接手及打开原记录。失效或撤权时立即清空相关展示。
6. **反馈。** 任务移除、切换当前企业、状态文字和报表更新保持稳定布局。用轻微、短时的进入反馈帮助定位。切企业时旧内容即时清除。状态更新的录屏应能辨认作用范围和真实结果。

## 先红后绿及验收

- 五企列表含未开始、正常、差异、待补件、结果待核查。负责人能从至少一个真实卡点打开准确对象并返回，参与人只看到已授权企业。不显示尚未汇总为零。
- 月结阻断→实际处理→复核后报表或可导出→交付包→客户实际签收，按已实现路径在本地跑通。正常/旧版本/撤权/错误回执均覆盖。某个外部环节只能合成验证时，注明真实边界。
- 跨企业、账期、长单位、大额、负值、两列差额、跨年、行业证据/原件缺失都可读。手机可查看和完成其允许的任务。桌面大表稳定，重载无显著视觉抖动。
- 设计评审留一组工作台、报表与客户端同品牌的对照图，一段打开卡点/回退/切企业及业务结果的录屏。用现有用例验证范围准确、路径完整与构建预算。
