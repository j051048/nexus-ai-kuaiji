# 阶段 02｜视觉基础、公共组件和壳层

完整继承 [执行总令](00_EXECUTION_MASTER.md)。前置为第 01 阶段的选定方向、品牌使用规范与动效表。本阶段交付登录及三类壳层的第一组实际改版，优先在没有归属冲突的文件落地。

## 范围和依赖

入口优先核对 `index.html`、`src/AuthScreen.tsx`、`AgentNavigation.tsx`、`ClientPortalShell.tsx`、`AdminWorkspace.tsx`、`AccountIdentity.tsx`、`AppPrimitives.tsx`、`tokens.css`、`agent-shell.css` 与 `styles.css`。当前已有壳层、图标、主题变量、原生 Modal、PageControls、EmptyState、Spinner 与导航高亮，先核实使用位置。

此阶段将生产变量、标识及公共组件定型。岗位业务、身份来源、导航权限和路由规则仍从现有契约读取。已在并行修改的 `WorkspaceHome.tsx` 等组件，由归属协调后进入下一阶段。

## 依次实施

1. **标识归一。** 从现有三柱图形和中文“衡账”的真实使用点入手，把选定的字标、小图形、亮底/深底/单色资源用到登录、会计与企业壳、管理端。浏览器图标及 theme-color 同步考虑。给产品名、当前角色和所属单位分配稳定位置，企业自己的名称或徽标与产品标识各有位置。英文副标如经评审保留，选定一套文案，在窄屏有省略规则。
2. **视觉变量映射。** 产出设计→生产变量表，涵盖画布/表面、字阶、正文和数字、分割线、主次按钮、成功/待判断/阻断/未知、间距、圆角、焦点与动效。保持单一生产来源，清理样板范围的局部十六进制值与过小业务字号。与现有 alias 共存时标出迁移路径，后续使用方全部迁移后再移除。
3. **组件状态样板。** 同屏检查主/次/文本按钮、危险操作、字段、标签、任务行、状态、提示、分页、空/加载/错误、弹层。给 hover、focus-visible、disabled、pending、错误、触控和高对比状态。区分“权限不足”“还缺资料”“版本过期”， disabled 有相应理由。复用现有 `Modal` 焦点机制及图标库。
4. **壳层重排。** 登录以清楚的中文产品识别和表单为主体。侧栏把常做任务放前，现有设置与帮助归入原位置。桌面与手机标题只出现一次。账号所属单位/身份、当前企业/账期随上下文准确显示。空间不足优先保留范围与主动作，弱化辅助文案。
5. **动效统一。** 用已有 CSS 时长实现选中、按钮、原生弹层和状态反馈。重点重测快速开关、切企业、退出、连续打开不同对象、减少动态效果及软键盘。成功提示由后端响应触发，播放进度与业务提交生命周期解耦。

## 先建验收

- 不同角色与兼任身份仍进入现有工作台，唯一导航高亮，单位/身份/当前企业可区分。显式路径、刷新、前进/后退及登录返回仍可恢复。
- 375/390 手机验证超长单位名、角色名、折叠导航和主按钮；1366/1920 验证静态对齐、阅读层级、紧凑与宽松密度。登录页键盘、正常/失败/MFA 状态保持可用。
- 颜色在白底、暖底与需要的深底上实测，品牌反白、数字、按钮图标和焦点都可辨认。暗底样张用于验证标志使用范围。
- 原生弹层打开、退回、Escape、快速开关、焦点恢复与减少动态效果有浏览器证据。没有可视觉继承的旧企业内容在切换时残留。

复用 `tax-i-shell.spec.ts`、`v01-visual-foundation.spec.ts`、`role2-firm-period.spec.ts`、`v09-navigation-history.spec.ts`、`qa-accessibility.spec.ts`、`reduced-motion.spec.ts` 与 `visual-foundation.test.ts`。为真实断点增补测试。当前候选过构建预算和两种基本设备视口后，给 03–05 冻结公共组件说明及可复用状态样板。
