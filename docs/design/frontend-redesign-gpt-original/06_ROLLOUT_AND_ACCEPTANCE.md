# 阶段 06｜全路由扩面与联合验收

完整继承 [执行总令](00_EXECUTION_MASTER.md)。前置为阶段 01–05 本地必验。同一候选逐路线核对截至当前的品牌与流程质量。

## 扩面

1. 从路由、导航和可直达链接生成页面清单。标记登录/身份、员工/客户、财务/会计、负责人、后台设置、通知/消息、打印/导出、外部结果、空/异常/无权页面的负责人、采用的公共组件、实际覆盖及交互状态。长尾页面先用基础版式统一，保留相应专业能力。
2. 逐路由查标志资产、任务字阶、企业/账期展示、金额、链接、字段、图标、当前状态和动效。仅清理已有证据显示无调用的遗留样式。公开生产 token 与 Open Design 样板的值/版本保持映射。把需要保留的例外写进现有组件说明。
3. 键盘、触控、浏览器缩放、打印、减少动态效果、慢加载和弱网使用同一场景评审。真实设备、微信内浏览器、人工读屏有条件就取得许可后实测，未跑注明。不得以 683px 视口替代真实 200% 缩放，以自动化扫描替代人工读屏。保留确切设备和浏览器信息。

## 联合验收矩阵

| 验收 | 最低证据 |
| --- | --- |
| 品牌和视觉 | 选定方向的字标/小图标/反白/黑白，长中文与金额样张，登录和五角色桌面/手机同候选对比图；说明具体问题、修复与接受原因 |
| 动效 | 员工交票、会计开原件、批量状态、切企业及撤权的正常/快速/慢网录屏；减少动态效果系统模式复跑，键盘焦点与真实状态可核对 |
| 核心业务 | 实际本地角色、API、PG 和原件存储跑员工交票→企业财务核验→会计独立复核→正式账务/导出→月度交付→签收；跨企业、跨期、部分成功、版本失效和权限变化至少有相应真实链或专项回归 |
| 浏览器及布局 | Chromium 375/390 手机、平板与 1366/1920 桌面核心场景；Firefox/WebKit 复核、原件、员工提交和返回关键子集。页面级 200% 缩放、横屏/短高度另记 |
| 可访问性 | 关键页面无 axe serious/critical 新问题；手工走键盘、焦点、弹层、中文输入和错误关联。对比度、实际触控目标和状态文案有证据，人工读屏单列 |
| 性能 | `npm run typecheck`、`npm run lint`、`npm run build`、`npm run test:frontend-budget`、相关 Vitest 及 dev/preview 核心浏览器结果。测首屏静态闭包和真实加载，保留冷/热、弱网数据，避免靠 CDN 字体、后移资源或放宽预算掩盖回归 |
| 权限与导出 | 复验工作台、附件、跨企业、来源版本、会计复核和导出路径。对接线影响的服务执行现有 PG16/17 门禁子集，按当前 FSC12 候选划分本地已验和其他待验 |

## 交付

- 一份可核对的前端验收记录，列阶段、路由、证据、候选、失败修复、未完事项、被共享文件阻断的具体范围及责任。列出实际跑过的命令和代码改动，产物统一存总令的分阶段目录。
- 一套可供后续继续使用的品牌和交互规范，包括设计资产、字体和授权、token 映射、版式密度、动效手册、颜色和状态用法、桌面/手机样板。业务控制以实际候选回归证明。
- 写清“Open Design 应用内是否导入、生成、预览，或仅使用本地品牌包与官方工作流”。视觉验收从同尺寸截图、录屏、任务过程和真实用户反馈各取证据。有用户参与才记录实际偏好和耗时。从本次 UI 验收独立标示外部试点、FSC12 运营能力和远端发布状态。
