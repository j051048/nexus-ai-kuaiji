# FSC17：车辆、资产、合同与保单的折旧摊销证据绑定

优先级 P1。先读 `docs/FSC_EXECUTION_MASTER_20261116.md` 及 `docs/FSC13_17_SUPPLEMENT_MASTER_20261117.md`。前置 FSC02 主数据与正式账务、FSC04 版本契约、FSC05 证据政策；复用通用周期计提及现有保险分摊。

## 目标与范围

让会计能从车辆查看相关资产、合同、保单、原件、累计计提和本月待办，并从每一笔折旧/摊销回到准确来源。重点是绑定、去重、版本和例外办理，不新建固定资产或保险计算平台。

先审查 `nexus_backend/app/periodic/service.py`、`periodic/reconciliation.py`、`periodic/models.py`、`tax/costs.py` 的保险分摊、运输主数据及其生效关系、`src/AssetReconciliation.tsx` 和现有周期计提/成本页面。已有漏提核对、尾差、处置和历史访问守卫必须继续保留。

## 实施

1. 采用企业内稳定车辆/资产身份，车牌是有生效期的标识而非资产唯一键。公司、资产、车辆、合同、保单各有自己的身份、版本与原件引用；仅有关联才链接，不要求每辆车必然是本企业固定资产，也不要求所有资产都有保单/租赁合同。
2. 区分固定资产折旧、长期费用/预付保险摊销及仅作证据的外部已计提结果。按批准政策确定核算权威与唯一生成路径；同一保险费用不能同时由 `TaxCostService` 和 `PeriodicService` 双重计提。多车保单按批准分配保留逐车贡献与未分配额。
3. 政策记录原值、残值、方法、使用期/受益期、起止月份或日期、科目及版本、分配维度、舍入/尾差、来源批准依据。现有引擎不支持的政策显示不支持，不偷偷用直线/整月公式替代；本轮不推定具体准则或税务折旧规则。
4. 生成/复核/记账/导出实际绑定资产、车辆关联、合同/保单（适用时）、政策和原件版本。需要车辆辅助核算时写入正式草稿/凭证的真实辅助值，并进入报表贡献，不只保存在旁表或页面标签。
5. 首月末月、换车/更名、保单增批/退保、资产处置、漏提补提、尾差和历史纠错均给影响预览；复用核对后计提与独立复核。退保不等于车辆处置，换车不等于新资产，自有/租入不自动互换分类。
6. 期间累计从已正式记账且更正关系可核对的历史计算，草稿/已撤销/重复源不误计入。跨月物理账套、跨年、身份迁移和恢复不复制出第二份资产/计提链。已锁期不覆盖，需调整时走原更正流程。
7. 在原资产和车辆页面就近增加关联摘要、原件、期初累计、本期、期末、尚未核实项及下一步。批量操作只准备可复核草稿，逐资产结果可定位；UI 不让用户手动改累计历史来强行对平。

## 先红后绿测试矩阵

- 车辆/合同/保单跨企业绑定；车牌复用误认为同资产；关联撤销后旧草稿仍被复核/记账/导出。
- 车辆维度只有旁表标签，正式分录辅助为空；多车保单分配超额或差额被悄悄丢弃。
- 同保单保险分摊与通用资产引擎重复生成；同资产同期间两会话重复计提；外部已计提回流再算一次。
- 两连续期间含跨年、首末月、残值、非整除尾差、零本期、漏提补提；总额不超批准基数，未知历史不补零。
- 未来续约误改历史已计提；车辆换牌重置累计；退保错误终止固定资产；实际处置后仍自动计提。
- 计提已复核后政策/科目/原件/关联版本变化；接受时撤权；锁期直接改资产历史或累计。
- 更正/红冲后累计未扣回或扣两次；跨期未完成运行绕过现有顺序守卫；恢复后重放再生成正式凭证。
- 只读或其他企业用户通过关联下钻/文件链接读到资产和原件；恢复后身份映射导致独立复核责任失真。

为支持的方法编写可人工核算的合成表：每期初始余额、本期合法计提、更正、累计、残值/未摊余额及逐车分配。期望值不调用被测函数生成。缺失旧历史/客户政策时应测试阻断及明确下一步，不造历史记录。

## 验收与交付

1. 本地真实服务链：建立资产及适用关联→核定政策/证据→两期计提→独立复核→正式记账/导出→一例退保和一例资产处置/漏提更正→凭证/车辆成本下钻核回。
2. 两企业隔离，PG16/17 受限角色直接 SQL 负向、并发重复计提、撤权/版本/锁期竞争和有数据迁移均通过。
3. 桌面/手机从待办到原件/差异/计提草稿/复核并返回，字段和状态不重复堆叠；未知历史显式可见。
4. 非空恢复覆盖稳定资产身份、车辆历史关联、政策/保单/合同版本、计提/分配/更正、复核、原件及导出。恢复前后累计与原件 hash 相等，恢复 hold 下不自动计提，受控解除后下一期可正常办理。
5. `docs/FSC17_ACCEPTANCE.md` 记录支持方法、关联/唯一来源契约、拒绝矩阵、红绿测试和候选；将完整数据夹具交给 FSC12 联合恢复。真实政策/退保凭证未提供时仍标外部待验。
