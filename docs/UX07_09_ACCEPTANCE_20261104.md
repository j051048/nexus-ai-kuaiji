## 07：会计跨客户连续办理

复用原月度服务单和服务器分页，不新建任务系统。

1. 新增全部客户、我负责、临期与逾期、待补件、待复核、待签收筛选。筛选条件在服务器分页和总数统计之前执行，仍限制在当前企业、账套、月份与授权范围。
2. “我负责”取最新服务计划的主办、复核或备份安排，不把有账套权限等同于已分配工作；安排本身不授予权限。
3. “临期与逾期”按服务期限截至未来 7 天计算，已签收的最新包不再计入。待补件取最新资料动作；待复核排除已失效来源。
4. “待签收”绑定当前最新月度包。下载、查看、导出回执核验均不能冒充客户签收；旧包签收后生成新包，新包仍待签收。
5. 每行给出负责人、期限、当前原因和下一步；有权限时进入现有服务单、复核或交付页。无权办理时只展示当前可读信息，不给可执行入口。
6. 返回保留月份、搜索、筛选、分页及已有滚动恢复。会计工作台可直接进入“客户月度工作”；员工或财务的兼任能力不自动改变主界面。

## 08：同屏复核与原凭证更正

1. 同屏复核保留当前状态、下一步、风险、制单责任和独立复核政策的直接展示。步骤说明、建议依据可展开，术语帮助放到事实和分录之后。
2. 正式凭证旁提供调整、冲销入口，复用已有手工凭证制单、复核和记账服务；不修改原凭证，不开放绕过锁期或审核的写入路径。
3. 原凭证种子核对事务所、企业、账套、正式记账状态、科目及版本、辅助维度和原件引用。金额按整数分转换；冲销交换原借贷，调整从零金额起由会计填写差额。
4. 提交前展示更正影响并要求确认；修改日期、说明、金额、科目或增删分录后，旧确认失效。成功提交后不继续显示同一张新建表单；未知提交结果保留原命令，先读取核对，不能自动另建。
5. 调整与冲销均走“提交待复核 → 另一位授权会计复核 → 确认正式记账”。制单人自审、未审记账、错账套原凭证、撤权后复核均被拒绝；重复记账命令返回原结果，关系只产生一条。
6. 只读或不可制单期间显示联系本账套主办会计及确认可办理期间的说明。没有实现反结账、追改历史期间或跨期自动转入；继续服从原服务的期间和权限政策。
7. 手机手工凭证金额保持单行，表格只在容器内横向滚动，避免把金额末位折到下一行。

## 09：按岗位突出主任务

- 员工先看到本人退回、待补件和待提交事项，再看到报销、采购/费用、日常收支三个已有入口。
- 企业财务保留“核验资料并移交会计”的主任务；会计提供跨客户月度工作入口；管理者先看需要协调的客户和人员安排，再看汇总与全部客户。
- 不增加首页模块，不新建导航壳。未知数量显示“查看清单”，读取中和失败各有说明；不把未知值伪装成 0，真实的 0 仍显示 0。
- 保持角色口径、键盘操作、返回来源和未保存内容保护；移动端标题、按钮和长内容不撑宽整页。
