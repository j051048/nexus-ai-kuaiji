## 实际模型运行

在隔离 Python 3.11 环境实际运行固定版本 PaddleOCR、PaddleX、PaddlePaddle，校验模型权重 SHA256，并通过完整 HTTP 接口识别虚构中文票据。金额、税额、日期、买卖方文字和输入像素坐标检查通过。

1400×700 合成票据请求内识别约 2.78 秒；2800×1400 版本约 4.38 秒。后者覆盖检测阶段缩至 2048 后坐标恢复到输入尺寸的情况。这是单机少量合成样本结果，不能外推生产吞吐量或客户票据准确率。详情见 [服务验收记录](../services/paddle_ocr/VALIDATION.md)。
