## 2. 角色 × 范围 × 导航 × 操作矩阵

| 角色 | 默认入口 | 首页主任务 | 导航/操作边界 |
|---|---|---|---|
| 客户员工 | ClientPortal | 本人提交、退回、补件 | 不显示会计配置/事务所运营 |
| 部门审批人 | WorkspaceHome | 本部门待审批 | 不显示其他部门明细；API 复核 |
| 客户财务/对接人 | WorkspaceHome | 财务核验、资料、移交 | 账套经办/复核仍需单独授权 |
| 客户领导 | ClientPortal/简报 | 有权访问的已发布结果 | 不显示未审内部数字；B04 正式报表未接前端 |
| 记账会计/复核人 | WorkspaceHome/Review | 异常、凭证复核、导出 | 复核与导出分开展示；服务端复核 |
| 事务所负责人 | Firm/Operations | 客户进度、风险、负荷 | 不默认展开技术日志 |
| 运维/技术管理员 | Admin | 账号、配置、费用、运行 | 不自动获得财务内容/复核权 |
| 多角色账号 | 服务端 profile | 当前企业当前能力 | 不合并跨企业权限；切换重新读取 |

**展示是导航辅助，不是授权来源。** 直接 URL、改 ID、下载和批量接口仍由 API 拒绝。

## 3. 首页与导航

### 3.1 首页

新增 `roleHomeGuide(profile)` 与服务端能力驱动的“当前职责与授权范围”面板：

- 当前身份与主任务；
- 当前可操作项（仅由 `can_submit/can_approve/can_finance/can_review/can_accounting/can_manage/can_operations` 推导）；
- 明确边界：“切换企业、直接链接、批量操作仍由服务端逐次校验”。

不新增前端角色判断作为权限；不把不同企业能力合并为全局最高权限。

### 3.2 导航

- 保留既有主导航、工作快捷入口、处理记录与管理。
- 会计工作区新增“会计工作台”入口，直接进入当前授权账套列表。
- 员工使用 ClientPortal 导航，不显示会计配置/事务所运营。
- 深链接和现有路由保留；未删除旧入口。

## 4. 同屏复核

复用 `InlineReviewDrawer` / `EvidenceViewer` / `JournalEntryGrid` / `AccountingContextAssistant`：

- 原件、事项、分录、金额、异常、证据引用同屏。
- 新增状态轴：审核状态、外部导出状态、事实版本；不把“已导出”写成“已记账”。
- 修改后旧审核失效：沿用后端版本/审核校验；前端在 dirty 时禁用确认审核。
- 原件加载/权限/证据过期显示错误，不用空白当“无附件”。
- 处理一项后保留队列位置，继续下一项；企业/期间标识始终显示。
- 窄屏采用分区/切换，不提供“一键通过”绕过证据核对。
- 助手作为侧栏，不替代表格/证据；沿用现有工具白名单。

## 5. 批量、交接与幂等

### 5.1 已有批量

- `QueueBatchDialog`：同企业附件批量识别，已有选择范围/预览/请求键。
- `MonthlyBatchDialog`：月初开期，已有逐户结果/进度；本批未改其业务范围。
- 选择范围、逐项回执、未知结果沿用现有后端。

### 5.2 工作交接绑定

新增：

- 预览返回 `plan_fingerprint`（稳定 JSON 哈希）。
- 执行请求携带 `plan_fingerprint`；后端重新计算并比对。
- 不一致返回 409“交接范围已变化，请重新预览”，不执行另一批范围。
- 前端 `MemberHandoverDialog` 保存预览指纹并在执行时发送；选择接替人变化会清空旧预览。

旧客户端不传 fingerprint 的兼容路径仍存在（legacy）；新 UI 必须绑定。

### 5.3 范围/分页

- 企业/任务列表服务端分页；不把前 100 条当全部。
- 批量预览与执行对象必须一致；超出上限提示分批。
- 关闭弹窗停止轮询不等于取消后台任务；仅服务端支持取消时提供取消。

## 6. 进度、敏感存储与作用域

- 导航偏好：现有 `WorkspaceHome` localStorage 保存筛选/分页/密度，不含 token/原件/分录正文。
- 复核命令标识：`review-session.ts` 仅内存保存，scope 变化清空。
- 查询竞态：`useScopedQuery` + WorkspaceHome epoch/AbortController；scope 变化中止、清空旧数据、丢弃迟到响应。
- 未保存正文不写长期 localStorage；离开时有明确阻断/保存/放弃。
- 登出/换账号/scope 变化清空页面数据；不复用旧企业内容。
- 不把财务资料放入 URL/普通日志/长期缓存。

---

## 7. 手机、上传与下载

- 复用现有 `IntakeWizard`、`upload-client` 两段式直传、附件状态和授权下载。
- 上传 100%/PUT 成功不等于附件已绑定；沿用申请→上传→完成→绑定→提交。
- 中断/过期/重复完成/切换企业迟到回调由上传/API 契约处理。
- 窄屏同屏复核保留金额、科目、依据、异常；不提供无法核对却能通过的快捷路径。
- 本批未重写上传组件；本轮只回归既有手机同屏复核。

---

## 8. 视觉与可访问性

- 延续现有品牌/组件/字体；新增角色面板和状态 pill 使用既有色板。
- 状态不只依赖颜色：文案明确“待会计审核/已审核/已导出/未导出”。
- 图标按钮有 aria-label；弹窗保留焦点返回；键盘快捷键不覆盖输入框。
- 手机宽度角色面板单列，主按钮/表格不整页横向溢出。
- 错误/空/无权/加载状态沿用现有组件；权限拒绝不显示为“暂无数据”。
