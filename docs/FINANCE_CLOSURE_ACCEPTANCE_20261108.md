## 固化的独立环境入口

```text
python scripts/c01_postgres_gate.py --config <显式本地四角色配置.json> --out <本轮全新报告目录>
```

配置只允许独立端口的 loopback 临时数据库和既有受限角色；管理连接需具备创建本地测试库的能力。该命令现在只借用源库的连接身份，每次创建一个新的数据库，不在源库运行夹具、不删除旧数据、不改旧账号权限。新库应用全部迁移并验证重入、checksum、PG 实际版本和持久化设置，开始时必须没有企业数据。

每次私有配置写到 `tmp_test/c01-private/<run_id>/config/`，独占创建、不覆盖历史配置；该目录不能位于公开报告目录内。报告只记录运行 ID 和配置摘要。根目录 `summary.json` 绑定完整前后端候选，具体 34 项原始结果位于 `verification/`。失败、超时、跳过、替换或重复用例均不能通过，原 600 秒执行上限保持不变。

CI 的 Accounting foundation 已改为直接调用这一入口，不再预先为 C01 建四个数据库后只用其中一个。AK05 原四组默认准备行为和冻结清单保持不变。**工作流修改尚未推送，不能据此声称远端 CI 已通过。**

本轮四个原本停止的本地 PG 测试集群已恢复为停止状态，端口 18500/18580 无监听残留。测试数据库和失败现场保留，没有删除其他智能体的环境。后续清理应按运行归属进行，不能删除整个 `tmp_test` 或私有配置根目录。
