# FSC14：租赁待审版本到正式记账、导出与归档

优先级 P0。先读 `docs/FSC_EXECUTION_MASTER_20261116.md` 与 `docs/FSC13_17_SUPPLEMENT_MASTER_20261117.md`。前置 FSC02 和 FSC13 权威契约；FSC05/06 的证据、待办及返回能力直接复用，不新增租赁专用审批引擎。这两项未完成可先推进独立后端修复，但不得把整条办理链标为通过。

## 目标、已有能力和范围

让会计从同一租赁事项完成合同依据核对→收入/退款等草稿→独立复核→按权威模式正式记账或外部办理准备→冻结导出→回执核对→归档，保留原始合同、计划、确认、版本和更正关系。

复用 `nexus_backend/app/tax/leases.py`、`src/TaxFPanel.tsx`、原复核抽屉、accounting 记账/更正、integrations 导出和回执、delivery 月度包/原件服务、FSC02 应收核销接口及 FSC13 权威契约。已有合同确认、发票红冲和 CSV 能力不重做；先核实是否仍有“只恢复合同 approved_version 就让旧稿重新导出”的缺口。

不做真实 T+ 发送或新租赁准则引擎；不把发票红冲当收入已冲销，不把收款当收入已确认，也不把合同批准当会计独立复核。

## 实施

1. 建立实际状态/关联表：合同及批准版本、计划行、业务/收款/发票事实、来源 hash、政策版本、草稿/复核版本、内部凭证、导出清单、外部回执、归档包。现有关系足够就补验证，不重复造表。
2. 收入、应收/预收、退款各自绑定经济事项身份，准确链接 FSC02 核销与规费。一个收费义务不能因走租赁和规费两入口而重复确认；相同客户、车辆、月份或金额并不证明是同一义务，必须有明确来源和合同计划关系。
3. 按 FSC13 的权威模式走正确路线：内部模式完成人工独立复核及正式记账；外部权威模式保留受控草稿/复核/冻结导出及外部结果核对，不为了满足流程图强制内部再记一次。两种路线都不得把“文件生成/导入接受”显示为外部正式记账。
4. 所有实际发布边界绑定生成时的合同/计划/政策/源版本。合同 v2 获批不能给 v1 草稿补签；受影响旧草稿须重新生成或经过有依据的差异更正和独立复核。仅影响未来期间的续约不应使无关历史正式记录被篡改。
5. 合同变更、终止、退款、红票、错期和已锁期分别显示处理办法。对已正式记账的影响通过现有冲销/更正追加，不改原凭证；同一次经济业务的更正与原业务严格关联，重复请求不多记。
6. 冻结文件保留清单版本、内容 hash、行来源与复核证据；接纳回执校验企业/账簿/期间/文件及版本。历史包可按当前权限审计查看，界面标历史版本；不提供伪装当前有效的再执行入口。
7. 在现有合同/计划行旁提供准确的“查看原件、去复核、去记账/准备导出、核对回执、查看归档”入口；只显示用户当前可办动作。完成后回原列表和期间，未完成项说明谁处理、缺什么，不留下死链接或一排同权重按钮。

## 必须先写的失败测试

- 合同 v1 草稿已复核，v2 改变该待执行草稿依赖的有效条款、服务期间、金额或依据，确认 v2 后 v1 仍通过单笔/批量/直接 API 导出或记账；必须拒绝而非只看当前 approved_version。另加正例：仅未来续约且原业务仍合法适用 v1 时，不应误拒合法办理或历史查询。
- 合同确认人被误当作凭证独立复核人；制单人经租赁特殊入口自审；同身份重映射恢复后绕过制单责任。
- 两入口对同一收费义务重复确认；合法不同费用因金额/车辆相同被误去重；收款登记自动确认全部收入。
- 部分/多次收款、预收跨月释放、退款、合同变更与已确认收入核回失败；必须按已批准政策和原业务关系确定处理，不硬编码“退款就冲收入”。
- 两个会话重复生成/记账/导出、撤权与接纳竞争、来源更新后旧下载/回执冒充当前；幂等与版本围栏同时有效。
- 发票红冲误改内部收入，合同终止删除历史，锁期后直接覆盖，未知外部结果自动重发。
- UI 显示已记账而没有正式凭证；显示已归档而清单缺引用；只读/其他企业可以下载原件或冻结包。

## 验收

1. 两企业、连续两期含跨年，用真实本地身份/API/PG/原件服务完成正常租赁和退款更正链。至少一例内部正式记账、一例明确标记的外部权威模拟链；不直接 SQL 补状态。
2. PG16/17 覆盖受限角色直写、同对象双会话、期间锁与版本变化、授权撤销；会计复核后才允许导出。
3. 桌面/手机从待办直达合同计划/原件，再到办理、返回；断言实际版本、金额和状态，不只截屏。
4. 非空恢复包括合同历史、确认、计划、核销/退款、更正、正式凭证、导出/回执/归档和 unknown。恢复后历史可核查，新一期可正常办理，不自动执行。
5. 输出 `docs/FSC14_ACCEPTANCE.md`，区分合同批准、会计复核、内部记账、外部结果、归档各层证据；真实合同政策和 T+ 认证缺失时不宣称真实业务已验。
