# PLT09-B 双月试点记分表

状态：**工具就绪，未采集真实数据**。本文件不填任何真实数字。

## 数据结构

一行 = 一个法人 × 一个岗位服务 × 一个期间（月）。样例 CSV 由
`python scripts/plt09_measurement.py --out ...` 生成，当前模板为
`docs/pilot/templates/measurement_baseline.csv`。

| 字段 | 含义 | 来源 | 空值 |
| --- | --- | --- | --- |
| `company_code/company_name` | 五家合成或经授权法人 | 组织档案 | 不允许 |
| `role_code/role_label` | 十五项岗位服务，R01–R15 | 本文件候选清单，待客户确认 | 不允许 |
| `period` | 会计期间 YYYY-MM | 账套 | 不允许 |
| `business_volume` | 对象数，按唯一身份去重 | 系统对象表或人工盘点 | 未采集 |
| `handled_minutes` | 经办人工分钟 | **人工记录**，不由时间戳推算 | 未采集 |
| `review_minutes` | 复核人工分钟 | **人工记录** | 未采集 |
| `waiting_internal_minutes` | 等待内部下一环节的分钟 | 系统状态停留，需固定状态映射 | 未采集 |
| `waiting_external_minutes` | 等待客户/银行/税局等外部方的分钟 | 人工或外部回执时间 | 未采集 |
| `rework_count` | 退回/返工次数 | 系统动作，按事件区分次数 | 未采集 |
| `line_excel_count` | 线下 Excel 使用次数 | 人工记录 | 未采集 |
| `expedite_count` | 人工催办次数 | 人工记录 | 未采集 |
| `first_pass_numerator/denominator` | 一次通过对象数 / 当期对象数 | 系统按固定 cohort | 未采集 |
| `error_review_count` | 复核发现的差错数 | 人工记录/复核动作 | 未采集 |
| `error_post_count` | 事后发现的差错数 | 人工记录 | 未采集 |
| `transferred_minutes` | 转移给业务人员的时间 | **人工记录** | 未采集 |
| `external_support_minutes` | 外部人员投入 | **人工记录** | 未采集 |
| `source` | `系统` / `人工` / `合成演练` / `未采集` | 采集说明 | `未采集` |

空值表示“未采集”，整数 `0` 表示“已确认零业务或零分钟”；两者不得互换。

## 汇总规则

- 按 `company × role × period` 汇总；企业内按岗位汇总，不做个人排名。
- 固定分母：当期创建的对象；对象后续变为已导出、已过账、已签收仍留在当期分母。
- 中位数、月末高峰、最长积压、人工兜底和外部投入分列；无法测的保持空值。
- 任何汇总行必须带 `coverage`：已采集格数 / 应有格数；覆盖不足不得给成功率结论。
- 系统可测字段与人工记录字段分列，不相互推算。

## 反作弊判定

以下任一成立，汇总显示“不能判定为成功”及原因，不显示减员或节省比例：

1. 复核积压较基线上升；
2. 事后发现差错较基线上升；
3. 转移给业务人员的时间上升；
4. 15 人与 5 人使用不同职责范围或业务量口径；
5. 存在未记录的外部援助；
6. 采集覆盖不足，或把未采集当零；
7. 变更了分母（例如对象过账后移出）而未在报告中披露。

## 采集边界

- 不采集键盘、鼠标、页面停留或屏幕内容用于评价个人。
- 采集页面必须写明范围、保存期限、可更正和审计留痕；默认只按岗位汇总。
- 本项目当前只有模板、空白 CSV 和合成演练；真实双月数据必须由客户财务在授权环境填写。
