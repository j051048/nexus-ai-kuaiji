## 系统尚无落点

- 独立“出纳”岗位角色与银行付款授权样本：当前未实现独立出纳身份，不得用企业财务代替。
- 404 已办完事项的“由谁何时办完”：review 可见 410 办理人/时间；其他类型仍统一不可见。
- 客户资料责任人的正式签字归档：目前只有 `material_requests` 和文书记录，未做客户签认原件专用流程。
- 集团层跨多法人合并报表：当前是管理汇总/授权账套投影，不是法定合并报表。

## 使用规则

- 责任人一栏为空时，任何模块不得以“已指定”写入验收通过。
- 职责变更必须同时更新系统授权、服务计划和本表；仅改本表不改变权限。
- 同一人可兼任部分职责，但制单、独立复核、付款办理的互斥约束按批准政策执行。
- 指派、备岗、转交不自动授予对象权限；每次访问由服务端重查当前授权。
